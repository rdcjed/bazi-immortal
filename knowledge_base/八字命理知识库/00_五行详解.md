# 五行详解

> 五行是八字命理和周易占卜的根基——金、木、水、火、土五种能量的生克制化，贯穿一切预测

---

## 一、五行基础

### 1.1 什么是五行

五行不是五种"物质"，而是**五种能量属性**。万物都可以归入这五类：

| 五行 | 特性 | 类比 | 代表能量 |
|------|------|------|---------|
| **木** | 生长、伸展、条达 | 树木发芽 | 向上的生命力 |
| **火** | 炎热、向上、光明 | 太阳火焰 | 向外散发的能量 |
| **土** | 承载、生化、包容 | 大地土壤 | 稳定包容的能量 |
| **金** | 清静、坚硬、肃杀 | 金属刀剑 | 收敛肃降的能量 |
| **水** | 寒冷、向下、滋润 | 江河湖海 | 向下潜藏的能量 |

## 二、五行生克（核心）

### 2.1 相生（谁生谁——母子关系）

> 相生 = 一种能量滋养、促进另一种能量

| 关系 | 公式 | 白话解释 |
|------|------|---------|
| **木生火** | 木→火 | 木头燃烧生火，树木提供燃料 |
| **火生土** | 火→土 | 火烧完变成灰烬（土），万物焚化归土 |
| **土生金** | 土→金 | 金属矿石从土里挖出来 |
| **金生水** | 金→水 | 金属熔化变液体，金属器皿冷凝出水 |
| **水生木** | 水→木 | 树木需要水才能生长 |

**记忆口诀：** 木火土金水（顺时针方向，前生后）

### 2.2 相克（谁克谁——制约关系）

> 相克 = 一种能量制约、抑制另一种能量

| 关系 | 公式 | 白话解释 |
|------|------|---------|
| **木克土** | 木→土 | 树木的根能破土而出 |
| **土克水** | 土→水 | 土能筑堤挡水 |
| **水克火** | 水→火 | 水能灭火 |
| **火克金** | 火→金 | 火能熔化金属 |
| **金克木** | 金→木 | 金属刀斧能砍树 |

**记忆口诀：** 木土水火金（隔一个相克）

### 2.3 五行生克关系图

```
           木
         ↙   ↘
      水       火
      ↑        ↓
      金  ←  土
```

- 实线箭头：相生（木→火→土→金→水→木）
- 虚线箭头：相克（木→土→水→火→金→木）

### 2.4 反生与反克（特殊情况）

> 生过头或克过头，会变成反效果

- **反生**：生得太多，被生者"受不了"
  - 木多火塞（柴太多火反而烧不起来）
  - 火多土焦（火太旺土被烧焦）
  - 土多金埋（土太厚矿石埋太深挖不出）
  - 金多水浊（金属太多水被污染）
  - 水多木漂（水太多树根泡烂）

- **反克**：被克者太强，反过来克"克它"的
  - 木坚金缺（木头太硬，斧头砍崩了）
  - 火炎水干（火太大，水被烧干了）
  - 土旺木折（土太硬，树根扎不进去）
  - 金多火熄（金属太多，火被压灭了）
  - 水泛土崩（水太大，堤坝被冲垮）

## 四、五行在八字中的应用

### 4.1 五行的"能量值"判断

看一个人的八字（四柱八个字），第一步就是看**五行分布**：

```
举例：某人八字
年柱  月柱  日柱  时柱
甲辰  丁卯  戊午  庚申

统计五行：
木：甲、卯、辰中乙 → 3个
火：丁、午 → 2个
土：戊、辰中戊、午中己 → 3个
金：庚、申 → 2个
水：辰中癸 → 1个
```

### 4.2 日主强弱判断

日干（日柱的天干）代表命主本人。看它的"力量"：

1. **得令**：日干生在旺它的季节（如木日主生在春天）
   - 得令则强，失令则弱
2. **得地**：地支中有日干的根（如木日主地支有寅卯）
3. **得生**：周围有生它的五行
4. **得助**：有同类五行相助

**强弱结论影响整个命局判断：**
- **身强**：喜克泄耗（喜官杀/食伤/财）
- **身弱**：喜生扶（喜印/比劫）

### 4.3 五行与十神的关系

十神就是**日干与其他干支的五行关系**：

| 关系 | 与日干的关系 | 对应的十神 |
|------|-------------|-----------|
| 同我 | 五行相同 | 比肩、劫财 |
| 我生 | 我生出的五行 | 食神、伤官 |
| 我克 | 我克制的五行 | 正财、偏财 |
| 克我 | 克制我的五行 | 正官、七杀 |
| 生我 | 生我的五行 | 正印、偏印 |

### 4.4 五行调候

不同季节出生的八字，需要不同的"调候"：

| 季节 | 特点 | 喜什么 |
|------|------|--------|
| 春（寅卯辰月） | 木旺、余寒未退 | 火来温暖 |
| 夏（巳午未月） | 火旺、炎热 | 水来降温 |
| 秋（申酉戌月） | 金旺、干燥 | 水来滋润 |
| 冬（亥子丑月） | 水旺、寒冷 | 火来取暖 |

## 五、五行在周易中的应用

### 5.1 卦的五行属性

| 卦 | 五行 |
|----|------|
| 乾、兑 | 金 |
| 震、巽 | 木 |
| 坎 | 水 |
| 离 | 火 |
| 坤、艮 | 土 |

### 5.2 体用生克中的五行

体卦（自己）和用卦（事情）的**五行生克关系**决定吉凶：

| 关系 | 五行 | 吉凶 |
|------|------|------|
| **体生用** | 我生他 | 我付出，泄气，辛苦但有好结果 |
| **用生体** | 他生我 | 大吉，有贵人相助 |
| **体克用** | 我克他 | 我能掌控局面，但费劲 |
| **用克体** | 他克我 | 大凶，事情压着你走 |
| **体用比和** | 五行相同 | 大吉，和谐顺利 |

### 5.3 卦气旺衰（五行+四季）

断卦要考虑**季节对卦气的强弱影响**：
- 体卦在旺相的季节 → 我强，能抗压力
- 体卦在囚死的季节 → 我弱，需要谨慎
