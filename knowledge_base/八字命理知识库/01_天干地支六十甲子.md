# 天干地支与六十甲子基础知识库

> 本文用大白话讲清楚八字命理最基础的知识：天干、地支、六十甲子。适合初学者入门，也适合智能体做八字推理的知识底子。

---

# 一、天干地支

## 十天干

十天干就是十个"字"，古人用来标记时间、方位、五行属性。按顺序背：**甲、乙、丙、丁、戊、己、庚、辛、壬、癸**。

### 阴阳属性

| 天干 | 阴阳 |
|------|------|
| 甲、丙、戊、庚、壬 | **阳**（刚、动、向外） |
| 乙、丁、己、辛、癸 | **阴**（柔、静、向内） |

口诀：**甲丙戊庚壬为阳，乙丁己辛癸为阴**。

### 五行属性

| 天干 | 五行 |
|------|------|
| 甲、乙 | **木**（甲为阳木/大树，乙为阴木/花草） |
| 丙、丁 | **火**（丙为阳火/太阳，丁为阴火/灯烛） |
| 戊、己 | **土**（戊为阳土/高岗，己为阴土/田园） |
| 庚、辛 | **金**（庚为阳金/刀剑，辛为阴金/珠宝） |
| 壬、癸 | **水**（壬为阳水/江河，癸为阴水/雨露） |

### 各天干特性详细说明

| 天干 | 五行 | 阴阳 | 类象 | 性格特征 | 季节对应 |
|------|------|------|------|----------|----------|
| **甲** | 木 | 阳 | 参天大树、栋梁 | 正直、积极、有担当，但也容易固执 | 春（孟春） |
| **乙** | 木 | 阴 | 花草藤蔓 | 柔韧、适应力强、有耐心，但也容易摇摆 | 春（仲春） |
| **丙** | 火 | 阳 | 太阳、烈火 | 热情、光明、大方，但也容易急躁 | 夏（孟夏） |
| **丁** | 火 | 阴 | 灯烛、炉火 | 温和、细腻、有灵性，但也容易内耗 | 夏（仲夏） |
| **戊** | 土 | 阳 | 高山、城牆 | 厚重、诚信、包容，但也容易保守 | 季夏/四季末 |
| **己** | 土 | 阴 | 田园、软土 | 谦逊、务实、善规划，但也容易多虑 | 季夏/四季末 |
| **庚** | 金 | 阳 | 刀剑、钢铁 | 刚毅、果断、有魄力，但也容易伤人 | 秋（孟秋） |
| **辛** | 金 | 阴 | 珠宝、金银 | 精致、敏锐、爱面子，但也容易挑剔 | 秋（仲秋） |
| **壬** | 水 | 阳 | 江河、大海 | 豁达、有智慧、善变通，但也容易泛滥 | 冬（孟冬） |
| **癸** | 水 | 阴 | 雨露、泉水 | 细腻、聪明、有谋略，但也容易阴郁 | 冬（仲冬） |

> 大白话：十天干就像十个性格不同的人。甲是大哥，乙是小姐姐，丙是阳光暖男，丁是文艺青年，戊是稳重大叔，己是管家婆，庚是硬汉，辛是精致boy，壬是浪子，癸是神秘少女。

## 十二地支

十二地支就是十二个"字"，对应生肖、月份、时辰。按顺序背：**子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥**。

### 阴阳属性

| 地支 | 阴阳 |
|------|------|
| 子、寅、辰、午、申、戌 | **阳** |
| 丑、卯、巳、未、酉、亥 | **阴** |

口诀：子寅辰午申戌阳，丑卯巳未酉亥阴。

### 五行属性

| 地支 | 五行 |
|------|------|
| 寅、卯 | **木**（寅为阳木/森林，卯为阴木/花木） |
| 巳、午 | **火**（巳为阴火/炉火，午为阳火/太阳） |
| 辰、戌、丑、未 | **土**（辰戌为阳土，丑未为阴土） |
| 申、酉 | **金**（申为阳金/矿石，酉为阴金/刀剑） |
| 亥、子 | **水**（亥为阴水/雨露，子为阳水/江河） |

### 地支与生肖、月份、时辰对照

| 地支 | 生肖 | 月份（农历） | 时辰 |
|------|------|-------------|------|
| **子** | 鼠 | 十一月 | 23:00-01:00（子时） |
| **丑** | 牛 | 十二月 | 01:00-03:00（丑时） |
| **寅** | 虎 | 正月 | 03:00-05:00（寅时） |
| **卯** | 兔 | 二月 | 05:00-07:00（卯时） |
| **辰** | 龙 | 三月 | 07:00-09:00（辰时） |
| **巳** | 蛇 | 四月 | 09:00-11:00（巳时） |
| **午** | 马 | 五月 | 11:00-13:00（午时） |
| **未** | 羊 | 六月 | 13:00-15:00（未时） |
| **申** | 猴 | 七月 | 15:00-17:00（申时） |
| **酉** | 鸡 | 八月 | 17:00-19:00（酉时） |
| **戌** | 狗 | 九月 | 19:00-21:00（戌时） |
| **亥** | 猪 | 十月 | 21:00-23:00（亥时） |

### 地支藏干

每个地支里面还藏着天干，这叫做"藏干"。看八字时，地支里藏的天干也能参与五行生克。完整表格如下：

| 地支 | 主气（本气） | 中气 | 余气 |
|------|-------------|------|------|
| **子** | 癸 | — | — |
| **丑** | 己 | 癸 | 辛 |
| **寅** | 甲 | 丙 | 戊 |
| **卯** | 乙 | — | — |
| **辰** | 戊 | 乙 | 癸 |
| **巳** | 丙 | 戊 | 庚 |
| **午** | 丁 | 己 | — |
| **未** | 己 | 丁 | 乙 |
| **申** | 庚 | 壬 | 戊 |
| **酉** | 辛 | — | — |
| **戌** | 戊 | 辛 | 丁 |
| **亥** | 壬 | 甲 | — |

> 大白话：地支就像一个小房间，里面住了几个人。子水房间里只住着癸水一个人；寅木房间里住着甲木（主人）、丙火（客人）、戊土（管家）。地支藏干在八字里叫"暗藏"的力量。

### 地支藏干口诀

```
子宫癸水在其中，丑癸辛金己土同。
寅宫甲木兼丙戊，卯宫乙木独相逢。
辰藏戊乙癸三重，巳藏丙戊庚相从。
午宫丁火并己土，未宫己乙丁共踪。
申藏庚壬戊，酉宫辛字丰。
戌宫戊辛丁，亥藏壬甲终。
```

### 地支关系表

#### 地支六合（两两相合，关系最亲密）

| 六合 | 说明 |
|------|------|
| **子丑合** | 土（子水+丑土 → 湿土） |
| **寅亥合** | 木（寅木+亥水 → 木更旺） |
| **卯戌合** | 火（卯木+戌土 → 生火） |
| **辰酉合** | 金（辰土+酉金 → 金更旺） |
| **巳申合** | 水（巳火+申金 → 生水） |
| **午未合** | 土（午火+未土 → 燥土） |

> 用法：八字里出现六合，代表两个人或两股力量关系密切、团结合作。

#### 地支三合（三三组合，形成一股强大的力量）

| 三合局 | 五行 | 说明 |
|--------|------|------|
| **申子辰** | 水局 | 申+子+辰 → 水势浩大 |
| **亥卯未** | 木局 | 亥+卯+未 → 木势旺盛 |
| **寅午戌** | 火局 | 寅+午+戌 → 火势熊熊 |
| **巳酉丑** | 金局 | 巳+酉+丑 → 金势坚固 |

> 用法：八字里凑齐三合局的三个字（或两个半合），代表某个五行力量极强。

#### 地支六冲（两两对立冲突）

| 六冲 | 说明 |
|------|------|
| **子午冲** | 水冲火，水火不相容 |
| **丑未冲** | 土冲土，同类相争 |
| **寅申冲** | 木冲金，金木相战 |
| **卯酉冲** | 木冲金，金木相战 |
| **辰戌冲** | 土冲土，同类相争 |
| **巳亥冲** | 火冲水，水火不相容 |

> 用法：八字里出现六冲，代表变动、冲突、分离。冲的双方力量相当则两败俱伤，一方强一方弱则弱的被冲走。

#### 地支六害（两两相害，暗中不和）

| 六害 | 说明 |
|------|------|
| **子未害** | 水害土 |
| **丑午害** | 午火生丑土，但丑午相害 |
| **寅巳害** | 木火相生但相害 |
| **卯辰害** | 木克土 |
| **申亥害** | 金生水但相害 |
| **酉戌害** | 金火相克 |

> 用法：八字里出现六害，代表暗中不和、小人是非、好事多磨。

#### 地支三刑（相互刑克，惹麻烦）

| 三刑 | 组合 | 说明 |
|------|------|------|
| **无礼之刑** | 子卯刑 | 子刑卯、卯刑子。代表不懂礼数、胡闹、招惹是非 |
| **恃势之刑** | 寅巳申刑 | 寅刑巳、巳刑申、申刑寅。代表仗势欺人、循环报复 |
| **无恩之刑** | 丑未戌刑 | 丑刑未、未刑戌、戌刑丑。代表忘恩负义、相互拆台 |
| **自刑** | 辰辰、午午、酉酉、亥亥 | 自己跟自己过不去，想太多、钻牛角尖 |

> 用法：八字里出现三刑，代表是非、官司、健康问题。但有些特殊格局反而要靠刑来"开库"（比如辰戌丑未全）。

# 二、六十甲子纳音

## 什么是六十甲子？

把十天干（甲~癸）和十二地支（子~亥）按顺序配对，天干轮回6次、地支轮回5次，正好配出60个组合，这就是**六十甲子**。古人用它来纪年、纪月、纪日、纪时。

### 纳音五行的用法说明

1. **看年命**：民间常说"你是金命还是火命"，指的就是年柱的纳音五行。比如1984年（甲子年）出生的人，纳音是"海中金"，俗称"金命"。

2. **辅助判断五行强弱**：纳音五行可以辅助判断原局的五行力量。比如两个干支的五行一样，但纳音不同，纳音的力量可以看作补充。

3. **特殊用法**：在更高级的技法中，纳音用于判断人的气质、职业倾向、适合的方位等。

> ⚠️ 注意：纳音五行和天干地支本身的五行是两个概念。比如甲子：天干甲属木，地支子属水，但纳音是海中金。不要搞混。

# 三、时间与干支对应

## 年柱

用六十甲子纪年，每60年一轮回。比如：
- 2024年 = 甲辰年（龙年）
- 2025年 = 乙巳年（蛇年）
- 2026年 = 丙午年（马年）

**口诀**：年柱看立春。过了立春才算下一年的干支，没到立春还是上一年的干支。

## 月柱

月份用十二地支对应，正月为寅，二月为卯……十二月为丑。天干根据年干来定，规律如下：

### 年上起月法（五虎遁口诀）

```
甲己之年丙作首，乙庚之岁戊为头。
丙辛之年寻庚起，丁壬壬寅顺水流。
若问戊癸何处觅，甲寅之上好追求。
```

大白话解释：

| 年干 | 正月（寅月）天干 | 举例 |
|------|-----------------|------|
| 甲年、己年 | 丙 | 甲年正月 = 丙寅月 |
| 乙年、庚年 | 戊 | 乙年正月 = 戊寅月 |
| 丙年、辛年 | 庚 | 丙年正月 = 庚寅月 |
| 丁年、壬年 | 壬 | 丁年正月 = 壬寅月 |
| 戊年、癸年 | 甲 | 戊年正月 = 甲寅月 |

> 实际用法：比如今年是丙午年，年干是"丙"，根据口诀"丙辛之年寻庚起"，正月就是庚寅月，二月辛卯，三月壬辰...以此类推。

## 日柱

日柱就是当天的干支。需要查万年历或日柱计算公式得到。**在排八字时，日柱是最重要的**，因为日干代表命主自己（"日主"或"日元"）。

> 注意：日柱以子时为界，不是以凌晨0点为界。晚上23点以后算第二天的干支。

## 时柱

时辰的干支，地支固定（如上文的时辰表），天干根据日干来定。

### 日上起时法（五鼠遁口诀）

```
甲己还加甲，乙庚丙作初。
丙辛从戊起，丁壬庚子居。
戊癸何方发，壬子是真途。
```

大白话解释：

| 日干 | 子时（23-1点）天干 | 举例 |
|------|-------------------|------|
| 甲日、己日 | 甲 | 子时 = 甲子 |
| 乙日、庚日 | 丙 | 子时 = 丙子 |
| 丙日、辛日 | 戊 | 子时 = 戊子 |
| 丁日、壬日 | 庚 | 子时 = 庚子 |
| 戊日、癸日 | 壬 | 子时 = 壬子 |

> 比如丙午日，日干是"丙"，根据口诀"丙辛从戊起"，子时就是戊子时，丑时己丑，寅时庚寅...以此类推。

## 完整八字示例

以**2026年6月8日 下午3:30**（北京时间）为例：

| 四柱 | 天干 | 地支 | 说明 |
|------|------|------|------|
| **年柱** | 丙 | 午 | 2026年，丙午年 |
| **月柱** | 甲 | 午 | 公历6月在芒种后，午月；丙年起庚寅，五月甲午 |
| **日柱** | 壬 | 戌 | 查万年历得 |
| **时柱** | 戊 | 申 | 下午3:30=申时；壬日起庚子，申时为戊申 |

> 完整八字：**丙午 甲午 壬戌 戊申**
