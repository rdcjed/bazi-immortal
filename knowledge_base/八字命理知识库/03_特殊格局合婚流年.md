## 一、特殊格局

> 普通格局看**扶抑**（身强用克泄，身弱用生扶）。特殊格局刚好相反——旺到极致或弱到极致时，顺着走反而更好。

### 1.1 从格

#### 从旺格（身强格）
八字中**比劫+印星占绝对主导**（80%以上），日主旺到极点，这时候不能克只能顺。

| 类型 | 条件 | 喜用 | 忌 |
|------|------|------|-----|
| **从旺格** | 比劫+印占绝对多数 | 顺其旺势，喜比劫印 | 官杀（克身） |
| **从强格** | 比劫+印旺+有食伤泄秀 | 喜食伤泄秀 | 官杀 |

#### 从弱格（身弱格）
八字中**克泄耗的五行占绝对主导**，日主弱到极点，扶不起来，只能顺其弱势。

| 类型 | 条件 | 喜用 | 忌 |
|------|------|------|-----|
| **从财格** | 财星占绝对主导 | 喜财、食伤（生财） | 比劫（夺财） |
| **从官格** | 官杀占绝对主导 | 喜官杀、财（生官） | 印（化官杀）、比劫（抗官） |
| **从儿格** | 食伤占绝对主导 | 喜食伤、财（泄食伤） | 印（克食伤） |

#### 从格判断口诀
```
旺之极者不可逆，顺其旺势反为吉
弱之极者不可扶，从其为吉是真途
从财从官从儿格，各有喜忌莫搞错
```

### 1.2 化气格

天干五合，合而化气，变成另一种五行：

| 合化 | 化气 | 条件 |
|------|------|------|
| 甲己合 | 化土 | 土的月份（辰戌丑未月） |
| 乙庚合 | 化金 | 金的月份（申酉月） |
| 丙辛合 | 化水 | 水的月份（亥子月） |
| 丁壬合 | 化木 | 木的月份（寅卯月） |
| 戊癸合 | 化火 | 火的月份（巳午月） |

> 化气格比较罕见，需要天干相合 + 化神当令 + 没有被破坏

### 1.3 专旺格

五行中**某一行特别专旺**，形成特殊格局：

| 格局 | 五行 | 特征 | 喜用 |
|------|------|------|------|
| **曲直格** | 木专旺 | 寅卯辰+甲乙木多 | 喜水木，忌金 |
| **炎上格** | 火专旺 | 巳午未+丙丁火多 | 喜木火，忌水 |
| **稼穑格** | 土专旺 | 辰戌丑未+戊己土多 | 喜火土，忌木 |
| **从革格** | 金专旺 | 申酉戌+庚辛金多 | 喜土金，忌火 |
| **润下格** | 水专旺 | 亥子丑+壬癸水多 | 喜金水，忌土 |

### 1.4 两气成像格

八字中**两种五行各占一半**，形成两行对峙：

| 组合 | 名称 | 特征 |
|------|------|------|
| 木+火 | 木火通明 | 聪明文采，适合文化 |
| 火+土 | 火土生成 | 实在稳重，适合实业 |
| 土+金 | 土金相生 | 诚信刚毅，适合金融 |
| 金+水 | 金水相涵 | 聪明灵活，适合贸易 |
| 水+木 | 水木相生 | 有才华，适合艺术 |

### 2.2 年柱合婚法

看年柱地支的**六合、三合、六冲、六害**：

- **六合**：子丑、寅亥、卯戌、辰酉、巳申、午未 → 最佳
- **三合**：申子辰、亥卯未、寅午戌、巳酉丑 → 很好
- **六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥 → 不佳
- **六害**：子未、丑午、寅巳、卯辰、申亥、酉戌 → 较差

### 2.3 日柱合婚法

看双方**日干关系**（最重要）：

```
相生日干：甲遇乙（木生火）、丙遇丁（火生土）等 → 佳
同生日干：乙遇乙、丁遇丁 → 可
相克日干：甲遇庚（金克木）、丙遇壬（水克火）等 → 需谨慎
```

### 2.4 五行互补

双方八字**五行互补**是最理想的：

| 男缺 | 女有 | 说明 |
|------|------|------|
| 缺木 | 木旺 | 女方能补男方 |
| 缺火 | 火旺 | 温暖对方 |
| 缺土 | 土旺 | 稳定对方 |
| 缺金 | 金旺 | 助对方决断 |
| 缺水 | 水旺 | 滋润对方 |

## 三、流年运势断法

### 3.1 大运与流年的关系

| 关系 | 含义 | 吉凶 |
|------|------|------|
| **岁运并临** | 大运=流年干支相同 | 大变动，吉凶都加倍 |
| **天克地冲** | 流年与大运天克地冲 | 重大变化，搬家/换工作/婚变 |
| **伏吟** | 流年与大运/命局相同 | 反复、停滞、旧事重来 |
| **反吟** | 流年与命局天克地冲 | 颠覆性变化 |
| **天合地合** | 流年与大运天合地合 | 好事、合作、婚嫁 |

## 四、完整断命流程

### 4.1 断命六步法

```
第1步：排八字 → 确定四柱八个字
第2步：定强弱 → 日主是强是弱？
第3步：取用神 → 用什么平衡命局？
第4步：看十神 → 十神组合代表什么？
第5步：看大运 → 当前走什么运？
第6步：断流年 → 今年什么情况？
```

### 4.2 案例一：普通人断流年

```
八字：甲子 丙寅 戊午 庚申
性别：男
当前大运：己巳（28-37岁）
流年：2026丙午年

分析：
1. 日主戊土，生在寅月（木旺），得丙火生 → 身强
2. 用神为金（泄土）、水（生木制火）
3. 大运己巳（火土运），对身强的人来说不太利
4. 2026丙午年，干支皆火，火旺生土 → 身更强了
5. 断：今年压力大，易急躁，宜静不宜动，注意心血管
```

### 4.3 案例二：感情合婚

```
男：庚午 戊寅 甲午 丙寅
女：甲戌 丙子 己亥 乙亥

合婚分析：
1. 生肖：马（男）配狗（女）→ 中平
2. 年柱：午+戌 → 半合火局 → 佳
3. 日干：甲（木）+ 己（土）→ 木克土 → 男方主导
4. 五行：男木旺缺金，女土旺缺木 → 互补
5. 结论：可配，但需要互相包容
```
