## 一、十二长生

### 什么是十二长生？

十二长生是描述**五行能量从出生到死亡、再到重生的完整生命周期**。它就像一个生物从生到死的全过程，八字里用来衡量天干在地支的**能量状态**——是强是弱、是旺是衰。

**简单理解**：把一天干放在一个地支上，看它在这个位置是"刚出生"还是"快死了"，能量有多大。

十二个阶段分别是：**长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养**。

---

### 十二个阶段详述

#### 1. 长生 —— 出生、开始

- **含义**：就像婴儿刚出生，生命力开始萌发。万物初生，生机勃勃。
- **吉凶**：**大吉**。代表新的开始、生命力强、有潜力。
- **四柱表现**：
  - 年柱长生 → 祖上积德，家世不错，出身好
  - 月柱长生 → 父母有能力，少年运好，得长辈提携
  - 日柱长生 → 自身能力强，身体健康，精力旺盛
  - 时柱长生 → 晚年运好，子女有出息

#### 2. 沐浴 —— 婴儿期、脆弱

- **含义**：婴儿出生后要洗澡，此时虽然活着但很脆弱。也叫"败地"，容易出问题。
- **吉凶**：**中性偏凶**。好看但不实用，容易有桃花、感情纠纷。
- **四柱表现**：
  - 年柱沐浴 → 早年感情丰富，家庭关系复杂
  - 月柱沐浴 → 父母感情纠葛，少年多情
  - 日柱沐浴 → 自身桃花多，婚姻易波折（也叫"咸池"）
  - 时柱沐浴 → 晚年桃花，子女多情

#### 3. 冠带 —— 少年、学习

- **含义**：古代男子成年要戴冠，代表学习成长阶段。像小孩上学，积累知识。
- **吉凶**：**吉**。代表学习能力强，有上进心。
- **四柱表现**：
  - 年柱冠带 → 家教好，少年得志
  - 月柱冠带 → 学业优秀，父母重视教育
  - 日柱冠带 → 自尊心强，有修养
  - 时柱冠带 → 晚年仍在学习进步

#### 4. 临官 —— 成年、任职

- **含义**：长大成人当官做事了，有社会地位，能独立谋生。
- **吉凶**：**大吉**。代表事业有成，有权力地位。
- **四柱表现**：
  - 年柱临官 → 出身官宦之家
  - 月柱临官 → 事业顺利，能得父母之力
  - 日柱临官 → 自身有能力做领导（也叫"建禄"）
  - 时柱临官 → 晚年事业稳定，子女有出息

#### 5. 帝旺 —— 壮年、鼎盛

- **含义**：能量达到顶峰，最旺盛的时候。就像人到中年，事业家庭都到了巅峰。
- **吉凶**：**大吉但物极必反**。旺到极点，但也意味着马上要走下坡路了。
- **四柱表现**：
  - 年柱帝旺 → 祖上极旺但易衰败
  - 月柱帝旺 → 中年运势巅峰
  - 日柱帝旺 → 自身极强，性格刚硬（也叫"羊刃"）
  - 时柱帝旺 → 晚年大起大落

#### 6. 衰 —— 衰退开始

- **含义**：巅峰已过，能量开始走下坡。身体、事业都在减弱。
- **吉凶**：**凶**。开始走霉运，做事力不从心。
- **四柱表现**：
  - 年柱衰 → 祖业凋零
  - 月柱衰 → 父母运势低落
  - 日柱衰 → 自身精力不足，容易疲倦
  - 时柱衰 → 晚年萧条

#### 7. 病 —— 生病、无力

- **含义**：能量进一步衰弱，像人老了生病。做什么都不顺，有心无力。
- **吉凶**：**凶**。多病多灾，做事困难。
- **四柱表现**：
  - 年柱病 → 祖上多病
  - 月柱病 → 父母身体不好
  - 日柱病 → 自身体质弱
  - 时柱病 → 晚年多病

#### 8. 死 —— 死亡、结束

- **含义**：能量耗尽，死亡。代表结束、终止、没戏了。
- **吉凶**：**大凶**。但也代表旧事物死亡，新事物将生。
- **四柱表现**：
  - 年柱死 → 祖上已故或无祖业
  - 月柱死 → 父母缘薄或已故
  - 日柱死 → 自身缺乏活力
  - 时柱死 → 子女缘弱

#### 9. 墓 —— 入墓、收藏

- **含义**：死后的归宿，埋进坟墓。但也是"入库"，能量被储藏起来，暂时不用。
- **吉凶**：**中性**。入库了，暂时用不上，但以后还能用。关键看冲开没有。
- **四柱表现**：
  - 年柱墓 → 祖业收藏，为人保守
  - 月柱墓 → 父母低调，家境一般
  - 日柱墓 → 自身容易隐藏才能
  - 时柱墓 → 晚年喜欢安静

#### 10. 绝 —— 灭绝

- **含义**：彻底消失。在地支中完全找不到这个五行的能量了。
- **吉凶**：**大凶**。代表绝境、没希望。但绝处逢生也是从这里开始的。
- **四柱表现**：
  - 年柱绝 → 出身贫寒
  - 月柱绝 → 父母困难
  - 日柱绝 → 自身陷入困境
  - 时柱绝 → 晚年艰难

#### 11. 胎 —— 受胎、孕育

- **含义**：绝之后重新开始受胎，新的生命在孕育中。虽然还没出来，但已经有了。
- **吉凶**：**吉**。代表新的希望，正在酝酿好事。
- **四柱表现**：
  - 年柱胎 → 祖上转好运
  - 月柱胎 → 父母有新机会
  - 日柱胎 → 自身有新计划
  - 时柱胎 → 晚年有新希望

#### 12. 养 —— 养育、蓄力

- **含义**：胎儿在母体中养育成长，积蓄力量等待出生。
- **吉凶**：**吉**。代表积蓄能量、准备中。
- **四柱表现**：
  - 年柱养 → 祖业积累良好
  - 月柱养 → 父母勤恳积蓄
  - 日柱养 → 自身善于积累
  - 时柱养 → 晚年安稳，子女孝顺

### 记忆口诀

#### 阳干顺行（甲丙戊庚壬）

阳干的长生位置记住这五个：

```
甲亥丙寅戊也寅，庚巳壬申顺行轮
```

意思就是：甲木长生在亥，丙火长生在寅，戊土长生在寅，庚金长生在巳，壬水长生在申。然后从长生顺数12个地支就是全部。

#### 阴干逆行（乙丁己辛癸）

阴干和对应的阳干是**对宫关系**（相差180度）：

```
乙午丁酉己也酉，辛子癸卯逆行求
```

意思就是：乙木长生在午（甲木长生在亥，午和亥是对宫），丁火长生在酉（丙火在寅，酉对寅），己土长生在酉（戊土在寅），辛金长生在子（庚金在巳），癸水长生在卯（壬水在申）。

**简单规律**：
- **阳干顺行**：甲→亥，丙→寅，戊→寅，庚→巳，壬→申，然后顺数
- **阴干逆排**：乙→午，丁→酉，己→酉，辛→子，癸→卯，然后逆数

#### 阴阳干的解释

为什么有阴阳干的区别？

- **阳干（甲丙戊庚壬）**：像男人，大气豪放，顺行。阳干要顺推。
- **阴干（乙丁己辛癸）**：像女人，内敛含蓄，逆行。阴干要逆推。

**本质**：阳生阴死，阴死阳生。甲木长生在亥，乙木死在亥；乙木长生在午，甲木死在午。阴阳同根，互为消长。

### 各天干旺衰详解

#### 甲木（阳木）
- **长生在亥**：亥水生甲木，刚生出来
- **帝旺在卯**：卯为木的旺地，甲木最强
- **死在午**：午火泄木气，甲木完了
- **绝在申**：申金克木，彻底没了

#### 乙木（阴木）
- **长生在午**：午火生乙木（火生土土生木...实际是乙木在午为长生是因为阴阳逆行）
- **帝旺在寅**：寅为木，乙木最强在寅
- **死在亥**：亥水虽生木但乙木阴干在亥为死
- **绝在酉**：酉金克乙木

#### 丙火（阳火）
- **长生在寅**：寅中藏丙火，刚生出来
- **帝旺在午**：午为火最旺
- **死在酉**：酉金耗火气
- **绝在亥**：亥水克火

#### 丁火（阴火）
- **长生在酉**：酉中藏丁火
- **帝旺在巳**：巳为火旺地
- **死在寅**：寅木生火但丁火在寅为死（阴阳相反）
- **绝在子**：子水克火

#### 戊土（阳土）
- **长生在寅**：寅中藏火生土
- **帝旺在午**：午火生土旺
- **死在酉**：酉金泄土气
- **绝在亥**：亥水耗土

#### 己土（阴土）
- **长生在酉**：酉中藏己土（实际为阴阳逆行）
- **帝旺在巳**：巳火生土

- **绝在子**：子水耗土

#### 庚金（阳金）
- **长生在巳**：巳中藏庚金，金生在巳
- **帝旺在酉**：酉为金最旺
- **死在子**：子水泄金气
- **绝在寅**：寅木耗金

#### 辛金（阴金）
- **长生在子**：子中藏辛金（阴阳逆行）
- **帝旺在申**：申为金旺地
- **死在巳**：巳火克金

#### 壬水（阳水）
- **长生在申**：申中藏壬水
- **帝旺在子**：子为水最旺
- **死在卯**：卯木泄水气

- **长生在卯**：卯中藏癸水（阴阳逆行）
- **帝旺在亥**：亥为水旺地
- **死在申**：申金生水但癸在申为死
- **绝在午**：午火耗水

## 三、十二长生在八字中的应用

### 在年柱

- **长生** → 祖上积德，出身好，有靠山
- **帝旺** → 祖上风光过，但容易败落
- **墓** → 祖上低调，有祖产但用不上
- **绝** → 出身贫寒，白手起家
- **胎养** → 祖上转好运，或出身一般但后劲足

### 在月柱

- **长生** → 父母有能力，少年运好
- **临官帝旺** → 家境殷实，父母有社会地位
- **病** → 父母体弱多病
- **死墓绝** → 父母缘薄，或早年离家

### 在日柱

日柱的十二长生对**自身影响最大**，是看一个人命格强弱的重要参考。

- **长生/临官/帝旺** → 自身强旺，做事有力，不容易被欺负
- **冠带** → 有学识修养，自尊心强
- **沐浴** → 桃花重，感情丰富，但容易有烂桃花
- **衰/病** → 身体弱，精力不足
- **死/墓/绝** → 自身能量不足，容易悲观，需大运补救
- **胎/养** → 有潜力，厚积薄发

### 在时柱

- **长生/临官** → 子女有出息，晚年享福
- **帝旺** → 子女能力强但个性强
- **沐浴** → 子女桃花重
- **胎养** → 晚年有新希望，子女发展潜力大
- **死墓绝** → 子女缘薄，或晚年孤独

### 四柱长生旺衰口诀

```
年柱长生祖上荫，月柱长生父母亲
日柱长生自身旺，时柱长生子女行

年柱帝旺祖风光，月柱帝旺家道昌
日柱帝旺个性强，时柱帝旺福满堂

年柱死绝祖无依，月柱死绝父母离
日柱死绝自身虚，时柱死绝晚景凄
```

### 旺衰在八字中的实际用法

#### 1. 看身强身弱

十二长生是判断日主（日干）强弱的重要工具之一。

- **日干在月令（月支）** 处于**长生、沐浴、冠带、临官、帝旺** → 身旺的可能大
- **日干在月令**处于**衰、病、死、墓、绝** → 身弱的可能大

> 注意：这只是参考之一，还要看整个八字的生克制化，不能只看十二长生。

#### 2. 看六亲状况

- 年柱代表祖上，年支的长生状态反映祖上情况
- 月柱代表父母，月支的长生状态反映父母情况
- 日支代表配偶，日支的长生状态反映配偶情况
- 时柱代表子女，时支的长生状态反映子女情况

#### 3. 看大运走势

大运地支走到日干的**长生或者帝旺**，一般是好运。走到**死墓绝**，一般不太好。

- 长生运 → 新机会、新开始
- 帝旺运 → 事业巅峰
- 衰病死运 → 低调求稳
- 墓绝运 → 谨慎保守

#### 4. 特殊组合

- **长生+驿马** → 出门发展有利
- **沐浴+桃花** → 桃花旺但有感情纠纷
- **帝旺+羊刃** → 个性极强，注意冲突
- **墓+库** → 有才华但不爱表现，冲开才好

## 四、四墓库

### 什么是四墓库？

四墓库就是十二长生中"墓"对应的四个地支：**辰、戌、丑、未**。

每个墓库都藏着一个五行的"仓库"：

| 墓库 | 属性 | 所藏五行 | 通俗说法 |
|------|------|----------|----------|
| **辰** | 土（湿土） | 水库 | 水的仓库 |
| **戌** | 土（燥土） | 火库 | 火的仓库 |
| **丑** | 土（湿土） | 金库 | 金的仓库 |
| **未** | 土（燥土） | 木库 | 木的仓库 |

### 辰为水库

- **辰中藏干**：戊土、乙木、癸水（水库）
- 壬水的墓在辰，癸水的墓也在辰
- 辰是湿土，本身含水很多
- **八字中有辰且水旺** → 水入库，平时用不上，遇冲（戌）则发

### 戌为火库

- **戌中藏干**：戊土、辛金、丁火（火库）
- 丙火的墓在戌，丁火的墓也在戌
- 戌是燥土，本身含火
- **八字中有戌且火旺** → 火入库，遇冲（辰）则发

### 丑为金库

- **丑中藏干**：己土、癸水、辛金（金库）
- 庚金的墓在丑，辛金的墓也在丑
- 丑是湿土，含水量不少
- **八字中有丑且金旺** → 金入库，遇冲（未）则发

### 未为木库

- **未中藏干**：己土、丁火、乙木（木库）
- 甲木的墓在未，乙木的墓也在未
- 未是燥土，含火气
- **八字中有未且木旺** → 木入库，遇冲（丑）则发

### 库与墓的区别

这是八字里很重要的概念，**库≠墓**，性质完全不同。

| 对比项 | 库 | 墓 |
|--------|-----|-----|
| **状态** | 五行旺而入库 | 五行衰而入墓 |
| **能量** | 能量还在，暂时收藏 | 能量已尽，彻底灭亡 |
| **比喻** | 把粮食存在仓库里 | 把死人埋进坟墓 |
| **八字表现** | 日主旺的人见了辰戌丑未是入库，以后还能用 | 日主弱的人见了辰戌丑未是入墓，救不回来 |
| **冲的作用** | 库被冲开 → 仓库打开，大展拳脚 | 墓被冲开 → 尸体被挖，大祸临头 |
| **吉凶** | 吉，等待时机 | 凶，无力回天 |

**判断口诀**：

```
旺者逢墓叫入库，收藏起来等时机
弱者逢墓叫入墓，进去就出不来了
```

**例1**：日主是壬水（旺），大运或流年遇到辰 → 水库打开了，水能发挥作用 → 好事。

**例2**：日主是壬水（弱得要命），大运或流年遇到辰 → 入墓了，水彻底没了 → 坏事。

### 墓库的冲与开

墓库的能量是**封存**的，需要"冲"才能打开：

| 墓库 | 冲开方式 | 效果 |
|------|----------|------|
| 辰（水库） | 见戌（辰戌冲） | 水库打开 |
| 戌（火库） | 见辰（辰戌冲） | 火库打开 |
| 丑（金库） | 见未（丑未冲） | 金库打开 |
| 未（木库） | 见丑（丑未冲） | 木库打开 |

**注意**：冲开墓库不一定都是好事，要结合日主旺衰：
- **日主旺** → 冲开是好事，能量释放
- **日主弱** → 冲开是坏事，虚脱无力

### 四墓库在四柱

- **年柱墓库** → 祖上藏富或祖上隐退
- **月柱墓库** → 父母低调保守
- **日柱墓库** → 自身有城府，深藏不露
- **时柱墓库** → 晚年安静养老

**四柱带墓库口诀**：

```
年柱带墓祖业藏，月柱带墓父母忙
日柱带墓人沉稳，时柱带墓晚景康
```

### 十二长生快速判断法

**拿到一个地支，怎么知道它对这个天干是什么长生状态？**

1. 先确定天干是**阳**还是**阴**
2. 阳干从该天干的长生地开始**顺数**到目标地支
3. 阴干从该天干的长生地开始**逆数**到目标地支

**例**：甲木在未是什么状态？
- 甲木是阳干，长生在亥
- 亥(长生)→子(沐浴)→丑(冠带)→寅(临官)→卯(帝旺)→辰(衰)→巳(病)→午(死)→**未(墓)**
- 答案：墓

**例**：乙木在申是什么状态？
- 乙木是阴干，长生在午
- 午(长生)→巳(沐浴)→辰(冠带)→卯(临官)→寅(帝旺)→丑(衰)→子(病)→亥(死)→戌(墓)→酉(绝)→**申(胎)**
- 答案：胎
