# 《穷通宝鉴》精要

> 《穷通宝鉴》原名《拦江网》，清代余春台整理。**最核心的命理经典之一**，专讲「调候用神」——按季节（月令）分析每个天干的喜忌，弥补了以日主强弱论命的不足。
>
> 本书的核心思想：**「夏生需水、冬生需火，春生需金修剪、秋生需水滋润」**

---

## 一、穷通宝鉴的核心方法论

### 与传统命理的区别

| 维度 | 传统身强身弱法 | 穷通宝鉴调候法 |
|------|--------------|---------------|
| 核心问题 | 我（日主）强不强？ | 这个季节我需要什么？ |
| 用神依据 | 身强喜克泄，身弱喜生扶 | 季节气候决定用神 |
| 最重视 | 日主强弱 × 四柱组合 | 月令气候 × 十神配合 |
| 优点 | 逻辑清晰，入门容易 | 实战精准，有大量经验验证 |
| 缺点 | 脱离季节实际情况(身弱但夏生未必不喜水) | 偏重实践经验，理论解释复杂 |

**最佳实践**：两者结合——先看日主强弱得出基础用神，再用穷通宝鉴的调候用神做调整修正。

### 穷通宝鉴的推理逻辑

```
① 看月令（出生月份的气候）
    ↓
② 看日干在这个月需要什么五行来"平衡气候"
    ↓
③ 看四柱有没有这个"所需五行"
    ↓
④ 有 → 富贵格局  无 → 寻常命格
    ↓
⑤ 再看十神配合定层次高低
```

> 为什么说穷通宝鉴「准得过份」？
> 因为它是数百年命师实战经验的总结。比如：
> - 甲木生在寅月，**不看八字都知道需要丙火**（寅月余寒未退）
> - 庚金生在申月，**需要丁火锻金成器**
> - 壬水生在子月，**需要戊土制水成堤**

## 二、十天干十二月调候详解

### 甲木（阳木）

| 月份 | 气候 | 调候用神 | 推理依据（大白话） |
|------|------|---------|-----------------|
| **寅月（立春~惊蛰）** | 春寒料峭，余寒未退 | **丙火**为主，癸水为辅 | 甲木初生需阳光（丙火）温暖照晒，一点癸水滋润即可。无丙火则木不发荣 |
| **卯月（惊蛰~清明）** | 仲春木旺，气候温和 | **庚金**为主，丙丁为辅 | 甲木正旺，需要庚金修剪（金的修剪）才能成栋梁。丙火辅助但不需太多 |
| **辰月（清明~立夏）** | 暮春土湿，木气渐退 | **癸水**为主，庚金为辅 | 辰月土旺，甲木需要癸水滋润（土润木生），庚金辅助修剪 |
| **巳月（立夏~芒种）** | 孟夏火炎，土燥 | **癸水**为主，丁火为辅 | 巳月火炎，甲木被焚（木生火反泄身），急需癸水滋润降温 |
| **午月（芒种~小暑）** | 仲夏火旺，酷热 | **壬癸水**为主，庚金为辅 | 火旺焚木，最需壬癸水来灭火滋润。庚金来生水亦可 |
| **未月（小暑~立秋）** | 季夏土燥，火炎土燥 | **癸水**为主，庚金为辅 | 未月火土皆燥，甲木急需癸水滋润，庚金辅助泄土生水 |
| **申月（立秋~白露）** | 孟秋金旺，火退气 | **丙火**为主，丁火为辅 | 申月金旺，金克木（官杀），需丙丁火来制金（食伤制杀），保护甲木 |
| **酉月（白露~寒露）** | 仲秋金旺，肃杀之气 | **丁火**为主，丙火为辅 | 酉月纯金克木更甚，需丁火炼金（丁火为灯烛，克金力度比丙火文雅） |
| **戌月（寒露~立冬）** | 季秋燥土，金退土旺 | **癸水**为主，庚金为辅 | 戌月土旺水弱，甲木急需癸水滋润润燥土。庚金生水辅助 |
| **亥月（立冬~大雪）** | 孟冬水旺，寒冷 | **丙火**为主，戊土为辅 | 亥月水旺木浮（水多木漂），需丙火温暖、戊土制水扎根 |
| **子月（大雪~小寒）** | 仲冬水旺，严寒 | **丙火**为主 | 子月水寒冻，甲木根部受冻无法生长，急需丙火温暖解冻 |
| **丑月（小寒~立春）** | 季冬寒土，水冻土寒 | **丙火**为主 | 丑月寒土冻水，甲木被冻。唯丙火可解（太阳照耀大地回暖） |

**甲木调候要诀**：春需金修，夏要水润，秋要火制金，冬要火暖身。

**乙木调候要诀**：乙木柔弱，**丙火最重要**（需要阳光），其次才是水润。

| 月份 | 气候 | 调候用神 | 推理依据 |
|------|------|---------|---------|

| **辰月** | 暮春土湿 | **壬水**为主 | 辰月土湿，壬水透出则火得润而成就（火土过旺则暗淡无光） |
| **巳月** | 孟夏 | **壬水**为主，庚金为辅 | 巳月丙火当令，火势熊熊。需壬水制火（水火既济），庚金生水源 |
| **午月** | 仲夏炎热 | **壬水**为主 | 午月丙火最旺，无水则火炎土燥、命局枯焦。壬水为救命之水 |
| **未月** | 季夏燥 | **壬水**为主 | 未月火余气，土燥。壬水润燥方为上格 |
| **申月** | 孟秋 | **壬水**为主 | 申月金旺生水，壬水得地。丙火有壬水相配则水火既济贵格 |
| **酉月** | 仲秋 | **壬水**为主 | 酉月金旺，丙火需壬水配合方显调和之美 |
| **戌月** | 季秋 | **甲木**为主，壬水为辅 | 戌月丙火渐退，需甲木来生火（木生火）。壬水辅助 |
| **亥月** | 孟冬 | **甲木**为主，壬水为辅 | 亥月水旺火弱，先需甲木来生火（木为火的印星），再用水配 |
| **子月** | 仲冬严寒 | **甲木**为主 | 子月水寒火绝，**最需甲木来生火**。无木则丙火无根 |
| **丑月** | 季冬严寒 | **甲木**为主 | 丑月寒土冻，丙火需甲木来生扶，木为丙火之印 |

**丙火调候要诀**：**夏需壬水成既济，冬需甲木续光明**。丙火不忌水（反而喜水相配），最怕无生源。

## 三、调候用神的实战应用

### 3.1 如何将穷通宝鉴用到八字推理中

**示例一**：甲木身弱，生于寅月，但按穷通宝鉴仍指出：**「寅月甲木，丙火为第一用神」**。

- 传统强弱法：身弱→喜水生扶 → 用壬癸水
- 穷通宝鉴：正月寒木需阳光→用丙火温暖
- **综合结论**：先用丙火去寒（调候），再用壬癸助根（强弱平衡）

**示例二**：丙火身旺，生于午月，穷通宝鉴说：**「壬水第一用神，水火既济方成贵格」**。

- 传统强弱法：身旺→喜克泄耗 → 用壬癸水克、用土泄
- 穷通宝鉴：夏火焚天→非壬水不能济
- **综合结论**：壬水为主要用神（不为克火而设，为成既济之势）

### 3.2 用神优先级

1. **第一优先级：调候用神**（穷通宝鉴法）——季节气候决定
2. **第二优先级：强弱用神**（身强身弱法）——平衡命局
3. **两者冲突时**：一般以调候为先（季节对命局的影响＞强弱）

> **例外情况**：当命局极端失衡时（如专旺格），特殊格局优先于调候。

### 3.3 调候成败判断

| 状态 | 判断 |
|------|------|
| **调候用神透干且有根** | 格局清透、富贵可期 |
| **调候用神在地支但有伤** | 福泽深厚但有波折 |
| **调候用神暗藏、待时而用** | 运势到来时方显 |
| **调候用神被克** | 怀才不遇 |
| **调候用神全无（命局干燥或寒冷）** | 寻常命格 |
