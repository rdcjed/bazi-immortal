# 天干地支深度解析

> 本文在《01_天干地支六十甲子》基础上，深入讲解天干地支的**形象数、配人体、配六亲、化气合冲刑害的深层用法**，以及在各柱中的具体应用。

## 一、天干形象数深度解析

### 1.1 天干配人体（形态对应）

天干不仅表五行，还对应人体部位的**形与气**：

| 天干 | 对应人体 | 详细说明（大白话） |
|------|---------|-----------------|
| **甲** | 头、胆 | 甲为阳木，形体最高，对应头部。甲木旺相→头大额宽；甲木受伤→头痛、胆疾 |
| **乙** | 颈项、肝 | 乙木为阴木、藤蔓，对应细长部位——脖子。乙木受伤→颈项不适、肝郁 |
| **丙** | 肩背、小肠 | 丙为太阳、光明，对应人体的上半身和后背。丙旺→肩背宽厚；丙弱→驼背含胸 |
| **丁** | 心、血液、眼 | 丁为灯烛之火，对应心脏和眼睛。丁火明亮→眼神有光；丁火受克→心脏不适、眼疾 |
| **戊** | 胃、肋、鼻 | 戊为高岗厚土，对应胃和鼻子。戊旺→鼻子高挺；戊弱→胃病、鼻塞 |
| **己** | 脾、腹 | 己为田园软土，对应腹部和脾脏。己强→腹部饱满；己弱→脾虚、小腹不适 |
| **庚** | 骨、大肠 | 庚为刀剑钢铁，对应骨骼。庚旺→骨架大、骨硬；庚弱→骨痛、肠疾 |
| **辛** | 肺、皮肤、牙齿 | 辛为珠宝金银，对应皮肤和肺。辛全→皮肤好、肺气足；辛伤→皮肤敏感、咳嗽 |
| **壬** | 膀胱、血液 | 壬为江河大水，对应血液和体液循环。壬旺→血液循环好；壬弱→水肿、膀胱问题 |
| **癸** | 肾、耳、骨髓 | 癸为雨露泉水，对应肾脏和耳朵。癸足→肾气足、听力好；癸弱→肾虚、耳鸣 |

> **八字推理中的应用**：四柱中某天干受伤（被克、无生、在地支无根）→对应的身体部位容易出问题。尤其是冲刑所在的位置更应重视。

### 1.3 天干纳音深层

六十甲子纳音五行不仅是「年命」，还有更深层的用法：

- **主流纳音辅助判断**：八字中某五行的干支数量基本可以判断强弱，但纳音可以在差别不大时做**辅助判断**
- **年柱纳音与月柱纳音的关系**：年命纳音生出月命纳音→上辈有助力；月命纳音生年命纳音→自力更生
- **四柱纳音五行统一**：四柱纳音五行一致→专一之象、在某领域有深厚积累
- **纳音克日主**：四柱纳音克制日主→一生压力大但有成就

## 三、天干五合深层用法

### 3.1 五合的正化与反化

天干五合不仅仅是「两个天干粘在一起」，它有**正化（成格用）和反化（不成格但仍有影响）**：

| 合 | 正化 | 反化条件 | 反化结果 |
|---|------|---------|---------|
| **甲己合** | 化土 | 甲旺己弱→甲不肯化 | 甲仍是木，贪合忘克 |
| **乙庚合** | 化金 | 乙旺庚弱→乙不肯化 | 仍是木金相克，但贪合反而减弱了克 |
| **丙辛合** | 化水 | 丙旺辛弱→丙不肯化 | 仍是火金关系，但贪合减克 |
| **丁壬合** | 化木 | 丁旺壬弱→丁不肯化 | 火水相冲，但合则减冲 |
| **戊癸合** | 化火 | 戊旺癸弱→戊不肯化 | 土水相克，贪合减克 |

**化气成格的条件**：必须是月令在化气的五行旺相、四柱的地支有助化五行之气、没有克化气五行的字出现。

### 3.2 天干五合的实践用法

1. **合化为用神** → 吉上加吉，富贵之象
2. **合化为忌神** → 凶上加凶，破财损身
3. **合而不化** → 双方力量都被羁绊（「贪合忘克」）：该克的不克了，该生的不生了
4. **争合（一甲合两己，一己合两甲）** → 感情复杂、三角关系

### 3.3 天干暗合

天干暗合是一种藏在地支中的合：

- **甲与己暗合**（甲见丑中己、己见寅中甲）
- **丙与辛暗合**（丙见戌中辛、辛见巳中丙）
- **戊与癸暗合**（戊见亥中癸、癸见巳中戊）

> 暗合代表**暗中勾结、私下来往**。大运流年遇到暗合，主暗箱操作、秘密合作。

## 四、地支合冲刑害进阶用法

### 4.1 地支六合进阶

每组合化出的五行是「合成之气」：

| 六合 | 合化五行 | 力量分析 | 实战应用 |
|------|---------|---------|---------|
| 子丑合 | 土 | 子被丑合，子水受制 | 合财库：丑为金库，子丑合打开金库 |
| 寅亥合 | 木 | 亥水生寅木，木更强 | 合印马：亥为甲木印、寅为马星，主远方得贵人 |
| 卯戌合 | 火 | 卯木生戌中丁火 | 合火食伤，主技术、才华 |
| 辰酉合 | 金 | 辰土生酉金 | 合金库，主财富 |
| 巳申合 | 水(变化较多) | 巳申合条件最复杂 | 巳申合化水/化火：水旺则化水，火旺则合而不化 |
| 午未合 | 土 | 午火生未土 | 合火土，主名望、信用 |

### 4.2 三合局进阶（半合与拱合）

**半合**（只出现三合局中的两个字）：

| 半合类型 | 组合 | 力量说明 |
|---------|------|---------|
| **生地半合** | 申+子(水局)、亥+卯(木局) | **力量最大**，相当于三合的80%力量 |
| **中神半合** | 子+辰(水局)、卯+未(木局) | 力量次之，约60% |
| **库地半合** | 申+辰(水局)、亥+未(木局) | 力量最弱，约40%但仍有三合之势 |

**拱合**（两个字中间夹一个，形成暗合之势）：

- **申+辰缺子** → 拱水局（暗中有水的力量，但不明显）
- **亥+未缺卯** → 拱木局
- **寅+戌缺午** → 拱火局
- **巳+丑缺酉** → 拱金局

### 4.3 地支三刑详解

**无礼之刑（子卯刑）**：
- 子刑卯：水多伤木，将帅无能累死三军
- 卯刑子：木多水缩，以下犯上
- **主**：不懂礼貌、桃花纠纷、晚辈不听话

**恃势之刑（寅巳申循环刑）**：
- 寅刑巳→巳刑申→申刑寅
- 这是环刑（三缺一也会刑）
- **主**：仗势欺人、纠纷不断、法律麻烦

**无恩之刑（丑未戌三刑）**：
- 丑刑未→未刑戌→戌刑丑
- 三个土互相刑克→开库（辰戌丑未全开→全局巨大变化）
- **主**：家庭纠纷、内部矛盾、房产纠纷
- **特殊用法**：丑未戌三刑反而能打开四库，使暗藏的五行通天透亮——对某些格局反而是好事

**自刑（辰辰、午午、酉酉、亥亥）**：
- 同一地支在命局中重复出现两次
- **主**：自己跟自己过不去、想太多、钻牛角尖、自寻烦恼

### 4.4 地支暗合

- **寅丑暗合**（寅中甲+丑中己）
- **午亥暗合**（午中丁+亥中壬、午中己+亥中甲）
- **卯申暗合**（卯中乙+申中庚）

> 暗合是**私下的、隐蔽的、不公开的**关系。大运流年引动暗合→婚外情、暗中交易。

### 4.5 地支三会方

三会方比三合局更强大——因为它代表的是**同一季节的全气**：

| 三会方 | 组合 | 力量 |
|--------|------|------|
| 寅卯辰会木 | 春三月全 | **最强木气** |
| 巳午未会火 | 夏三月全 | **最强火气** |
| 申酉戌会金 | 秋三月全 | **最强金气** |
| 亥子丑会水 | 冬三月全 | **最强水气** |

> 三会方力量大于三合局，因为它是「季节之力」而不仅是「组合之力」。

## 六、干支应用综合示例

### 6.1 天干伤病对应

> 年柱天干为甲（头部），被庚（刀剑金）冲克，且在地支无根 → 易有头部外伤、偏头痛

### 6.2 地支六冲身体对应

> 月支为卯（肝/眼睛），流年酉冲月柱 → 该年容易肝火旺、眼部不适、情绪波动

### 6.3 三刑对应

> 命局有寅巳申三刑 → 一生容易招惹是非、卷入法律纠纷。如果三刑有制（天干透出制刑的字），则能将压力转化为动力

> 命局有丑未戌三刑 → 家庭内部矛盾、房产纠纷。若刑而开库，反而能得暗藏之福

### 6.4 天干五合对应

> 甲己合而化土为用神 → 土能生金（用神），则该人有**团结凝聚之力**，合作伙伴多有助力

> 丙辛合而不化（火旺金弱）→ 丙火想合辛金但辛金不肯，代表**一厢情愿的感情/投资**
