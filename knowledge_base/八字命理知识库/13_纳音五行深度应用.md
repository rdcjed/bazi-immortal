# 纳音五行深度应用

> 纳音五行是六十甲子的"音律五行"——每个甲子组合对应一种纳音五行，如"甲子乙丑海中金"。纳音五行在合婚、断命、流年预测中有独特作用，是正五行的补充和深化。

---

## 一、什么是纳音五行？

**纳音五行** = 六十甲子每两个天干地支组合对应一种五行，共30种纳音。

**原理：** 古代以音律配五行，天干地支的音律相合，产生不同的"音"，每种音对应一种五行属性。

## 二、纳音与正五行的关系

### 2.1 纳音五行与正五行的区别

| 对比项 | 正五行 | 纳音五行 |
|--------|--------|---------|
| **来源** | 天干地支本身的五行属性 | 六十甲子组合的音律五行 |
| **数量** | 5种（金木水火土） | 30种（每种五行6种纳音） |
| **作用** | 判断日主旺衰、生克制化 | 合婚、断命细节、流年预测 |
| **层次** | 基础层，决定命局大势 | 深化层，补充细节 |
| **应用** | 排盘、取用神、断旺衰 | 合婚、断性格、流年应期 |

### 2.2 纳音五行的生克关系

纳音五行也遵循金木水火土的生克规律：

| 纳音五行 | 生 | 克 | 被生 | 被克 |
|---------|----|----|------|------|
| **纳音木** | 纳音火 | 纳音土 | 纳音水 | 纳音金 |
| **纳音火** | 纳音土 | 纳音金 | 纳音木 | 纳音水 |
| **纳音土** | 纳音金 | 纳音水 | 纳音火 | 纳音木 |
| **纳音金** | 纳音水 | 纳音木 | 纳音土 | 纳音火 |
| **纳音水** | 纳音木 | 纳音火 | 纳音金 | 纳音土 |

> 💡 **注意：** 纳音五行的生克力量比正五行弱，一般作为辅助参考，不能替代正五行的生克。

## 三、纳音五行在合婚中的应用

### 3.1 合婚纳音五行原则

合婚看纳音五行，主要看**年柱纳音**的相生相克：

| 纳音关系 | 含义 | 吉凶 |
|---------|------|------|
| **纳音相生** | 一方纳音生另一方纳音 | 吉，夫妻和睦，互相扶持 |
| **纳音相同** | 双方纳音相同 | 吉，志同道合，相处融洽 |
| **纳音相克** | 一方纳音克另一方纳音 | 凶，夫妻不和，矛盾多 |
| **纳音相冲** | 双方年支相冲 | 凶，缘分浅，易分离 |

### 3.2 合婚纳音五行对照表

| 男命纳音 | 女命纳音 | 关系 | 吉凶 |
|---------|---------|------|------|
| 海中金 | 大林木、松柏木、石榴木、桑柘木、杨柳木 | 金克木 | 凶 |
| 海中金 | 炉中火、山下火、霹雳火、天上火、佛灯火、山头火 | 火克金 | 凶 |
| 海中金 | 涧下水、天河水、长流水、大海水、泉中水 | 金生水 | 吉 |
| 海中金 | 海中金、沙中金、白蜡金、金箔金、剑锋金、钗钏金 | 同类 | 吉 |
| 海中金 | 城头土、屋上土、大驿土、壁上土、路旁土、沙中土 | 土生金 | 吉 |

### 3.3 合婚纳音断法口诀

```
纳音相生夫妻和，纳音相克矛盾多。
纳音相同情投意，纳音相冲缘分薄。
男金女木金克木，男木女金木克金。
男火女水水克火，男水女火火克水。
男土女木木克土，男木女土土克木。
```

## 七、实战应用方法

### 7.1 纳音合婚三步法

**第一步：查双方年柱纳音**
- 查六十甲子纳音表，确定双方年柱纳音

**第二步：判断纳音关系**
- 相生 → 吉
- 相同 → 吉
- 相克 → 凶
- 相冲 → 凶

**第三步：综合判断**
- 纳音吉 + 正五行吉 → 上等婚配
- 纳音吉 + 正五行平 → 中等婚配
- 纳音凶 + 正五行吉 → 中等婚配
- 纳音凶 + 正五行凶 → 下等婚配

### 7.2 纳音断命三步法

**第一步：查四柱纳音**
- 查六十甲子纳音表，确定四柱纳音

**第二步：判断纳音配合**
- 四柱纳音相生 → 吉
- 四柱纳音相克 → 凶
- 四柱纳音相同 → 吉
- 四柱纳音混杂 → 平

**第三步：结合正五行断命**
- 纳音吉 + 正五行吉 → 上等命
- 纳音吉 + 正五行平 → 中等命
- 纳音凶 + 正五行吉 → 中等命
- 纳音凶 + 正五行凶 → 下等命
