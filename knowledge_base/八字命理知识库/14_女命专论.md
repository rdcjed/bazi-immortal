# 女命专论

> 女命八字有独特的断法——婚姻、子女、财运事业是女命的三大核心。女命看婚姻以官杀为夫星、日支为夫宫；看子女以食伤为子女星、时柱为子女宫。现代女命断法需结合时代特点进行调整。

## 一、女命看婚姻的核心方法

### 1.1 官杀为夫星

女命以**正官**和**七杀**为夫星：

| 十神 | 含义 | 婚姻表现 |
|------|------|---------|
| **正官** | 正夫、合法配偶 | 婚姻稳定、配偶正直、感情专一 |

| **正官+七杀** | 官杀混杂 | 婚姻不顺、感情多变、易有外遇 |

### 1.2 日支为夫宫

**日支** = 婚姻宫，代表配偶的家、婚姻的状态：

| 日支十神 | 婚姻表现 | 配偶特征 |
|---------|---------|---------|
| **日支为正官** | 婚姻稳定，配偶正直 | 配偶有责任感，事业稳定 |

| **日支为正财** | 婚姻稳定，配偶顾家 | 配偶经济条件好，会理财 |
| **日支为偏财** | 婚姻一般，配偶大方 | 配偶花钱大手大脚，不拘小节 |
| **日支为正印** | 婚姻稳定，配偶包容 | 配偶性格温和，有文化 |
| **日支为偏印** | 婚姻一般，配偶孤僻 | 配偶性格内向，不善交际 |
| **日支为食神** | 婚姻稳定，配偶温和 | 配偶性格好，会照顾人 |
| **日支为伤官** | 婚姻不顺，配偶叛逆 | 配偶脾气大，不服管 |
| **日支为比肩** | 婚姻一般，配偶平等 | 配偶性格像朋友，平起平坐 |

官杀混杂婚姻乱，一官一杀情难定。
日支为夫宫所在，看夫宫知婚姻状。
夫宫逢冲婚姻动，夫宫逢合婚姻稳。

| 情况 | 男命 | 女命 |
|------|------|------|
| **阳年（甲丙戊庚壬）** | 顺排 | 逆排 |
| **阴年（乙丁己辛癸）** | 逆排 | 顺排 |

**举例：** 女命甲子年生（阳年）
- 男命：顺排（甲子→乙丑→丙寅……）
