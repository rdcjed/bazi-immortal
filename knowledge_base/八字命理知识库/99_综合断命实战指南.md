## 二、各步骤详细操作

### 第一步：八字排盘

**输入：** 出生年份、月份、日期、时辰、性别

#### 排年柱
```
年柱以立春为界：
例：2026年2月4日（立春）前 → 乙巳年
    2026年2月4日（立春）后 → 丙午年
```

#### 排月柱
```
月支固定（寅月=立春~惊蛰、卯月=惊蛰~清明…）
月干用五虎遁：
  年干为甲己 → 月干从丙开始
  年干为乙庚 → 月干从戊开始
  年干为丙辛 → 月干从庚开始
  年干为丁壬 → 月干从壬开始
  年干为戊癸 → 月干从甲开始
```

#### 排日柱
```
1900-1999年：日干支基数 = (年尾二位数+3)*5 + 55 + (年尾二位数-1)/4
2000-2099年：日干支基数 = (年尾二位数+7)*5 + 15 + (年尾二位数+19)/4
（取mod60得干支序号，加上当年天数，取mod60）
```

#### 排时柱
```
时支固定（23-1=子时，1-3=丑时…）
时干用五鼠遁：
  日干为甲己 → 时干从甲开始
  日干为乙庚 → 时干从丙开始
  日干为丙辛 → 时干从戊开始
  日干为丁壬 → 时干从庚开始
  日干为戊癸 → 时干从壬开始
```

### 第二步：分析命局（最关键一步）

#### 2.1 定日主强弱

**四看原则：**

| 判断维度 | 内容 | 权重 |
|---------|------|:----:|
| ① 得令 | 日主生在旺它的季节 | ⭐⭐⭐ |
| ② 得地 | 地支有日主的根（本气藏干） | ⭐⭐⭐ |
| ③ 得生 | 周围有生它的五行（印星） | ⭐⭐ |
| ④ 得助 | 有同类五行（比劫） | ⭐⭐ |

**强弱判断标准：**
```
得令+得地 → 身强
得令+不得地 → 中强
不得令+得地+得生 → 中弱
不得令+不得地 → 身弱
四条占三条以上 → 极强（可能入从格）
四条都不占 → 极弱（可能入从格）
```

#### 2.2 五行分布

```
计算四柱八个字中五行各出现几次：
木：__次  火：__次  土：__次  金：__次  水：__次

缺的五行 → 可能是命局的"病"
多的五行 → 可能是命局的"药"
```

#### 2.3 查特殊格局

**先判断是否入特殊格局，再判断普通格局：**

```
① 是否从旺格？→ 比劫+印占80%以上
② 是否从弱格？→ 克泄耗占80%以上
③ 是否专旺格？→ 某一种五行独占
④ 是否化气格？→ 天干有合且化神当令
⑤ 以上都不是 → 普通扶抑格局
```

#### 2.4 定用神忌神

**身强：** 喜克泄耗（官杀/食伤/财），忌生扶（印/比劫）
**身弱：** 喜生扶（印/比劫），忌克泄耗（官杀/食伤/财）
**从旺：** 喜生扶，忌克泄
**从弱：** 喜克泄，忌生扶

```
用神 = 对命主最有利的五行
忌神 = 对命主最不利的五行
喜神 = 辅助用神的五行
```

### 第三步：十神分析

#### 3.1 列出十神

以日干为"我"，与其他干支的关系：

| 关系 | 对应的十神 |
|------|-----------|
| 与我五行相同 | 比肩（同阴阳）、劫财（不同阴阳） |
| 我生的五行 | 食神（同阴阳）、伤官（不同阴阳） |
| 我克的五行 | 正财（同阴阳）、偏财（不同阴阳） |
| 克我的五行 | 正官（同阴阳）、七杀（不同阴阳） |
| 生我的五行 | 正印（同阴阳）、偏印（不同阴阳） |

#### 3.2 十神组合常见格局

```
官印相生 → 有官有权，正道发展
杀印相生 → 有魄力有学历，乱世英雄
伤官配印 → 才华横溢，名利双收
食神生财 → 福气好财运好，轻松致富
伤官见官 → 是非多、易惹官非
比劫夺财 → 破财、合伙不利
财星破印 → 为钱奔波、与长辈不合
枭神夺食 → 多灾多难，福气被夺
```

#### 3.3 通过十神断性格

```
比劫旺 → 讲义气但冲动，朋友多花销大
食伤旺 → 聪明有才华，但傲气
财星旺 → 注重物质，财运好但容易贪
官杀旺 → 责任心强但压力大
印星旺 → 有学识但保守依赖
```

### 第四步：大运流年

#### 4.1 起运时间

```
阳年男、阴年女 → 顺排（生日→下一个节气）
阴年男、阳年女 → 逆排（生日→上一个节气）

三天 = 一岁运
一天 = 四个月运
一个时辰 = 十天运
```

#### 4.2 大运排法

```
每十年换一个大运，共排6-8步大运（60-80年）
大运干支从月柱开始顺/逆排
```

#### 4.3 流年判断

看流年干支与命局、大运的关系：

| 关系 | 可能事件 |
|------|---------|
| 流年=用神 | 好事、机遇 |
| 流年=忌神 | 坏事、压力 |
| 岁运并临 | 重大变化 |
| 天克地冲 | 变动、冲突 |
| 天合地合 | 合作、喜事 |
| 流年逢驿马 | 变动、出差 |
| 流年逢桃花 | 感情机会 |
| 流年逢华盖 | 独处、思考 |

### 第五步：综合解读模板

#### 模板一：整体运势

```
【八字】甲子 丙寅 戊午 庚申
【日主】戊土（身强）
【用神】金（泄土）、水（生木制火）
【忌神】火（生土）、土（帮身）

整体评价：
您的八字戊土日主，生在寅月得丙火相生，
属于身强格局。性格稳重有主见，
但容易固执。用神为金、水，
补足会更加顺利。

当前大运：己巳（火土运）

今年火土两旺，对您来说是忌神年，
建议以守为主，谨慎投资，注意健康。
```

#### 模板二：分领域解读

```
【事业】官杀为用，适合管理岗位或创业。
        今年流年七杀，压力大但也是机会。

        今年偏财不显，不宜投机。

        今年桃花不旺，专注于自我提升。
```

## 三、综合断命示例

### 案例一：年轻人问事业

```
出生：2000年8月15日 14:30  男
八字：庚辰 甲申 壬申 丁未

排盘分析：
日主壬水，生在申月（金旺，水相）
→ 得令 ☆☆☆
地支申申辰半合水局 → 得地 ☆☆☆
天干庚金生水 → 得生 ☆☆
→ 身强

用神：木（泄水）、火（调候）、土（制水）
忌神：金、水

十神组合：
年干庚为偏印 → 学业不错
月干甲为食神 → 有才华
时干丁为正财 → 财运稳定

当前大运：癸未（金水运忌）
当前流年：丙午（火为用神）

结论：
今年运势不错！丙午流年火旺为用神，
事业上有发展机会，财运看好。
建议抓住机遇，但注意不要冒进。
```

### 案例二：中年人问财运

```
出生：1985年3月20日 8:00  女
八字：乙丑 己卯 甲午 戊辰

排盘分析：
日主甲木，生在卯月（木旺）
→ 得令 ☆☆☆
地支卯+辰中乙木 → 得地 ☆☆
→ 身强

用神：金（克木）、火（泄木）
忌神：水、木

十神组合：
月干己为正财 → 稳定收入
年干乙为劫财 → 有竞争、花销大
时干戊为偏财 → 偏财运

当前大运：壬午（水火运）
当前流年：丙午（火为喜）

结论：
今年火旺泄木，对您有利！
偏财运不错，有机会获得额外收入。
但比劫在年柱，注意合伙投资要谨慎。
建议在夏季（火旺）把握机会。
```

### 案例三：感情合婚

```
男命：庚午 戊寅 甲午 丙寅（木旺身强）
女命：甲戌 丙子 己亥 乙亥（土弱身弱）

合婚分析：
① 生肖：马+狗 → 中平
② 年支：午+戌 → 半合火局 → 佳
③ 日干：甲+己 → 合化为土 → 佳
④ 五行：男木旺、女土弱 → 互补
  男方木克女方土 → 男方主导
⑤ 大运同步：未来十年同步走火运 → 同步

结论：双方八字匹配度中等偏上，
适合结婚，但需注意沟通方式。
```

## 四、智能体断命建议

### 4.1 给智能体的输出规范

**回答用户时，建议按以下结构：**

```
1. 您的八字是：XXXX
2. 五行分布：X木、X火、X土、X金、X水
3. 日主强弱：身强/身弱
4. 命局特点：一句话总结
5. 用神忌神：
6. 当前运势：大运+流年判断
7. 分领域建议：
   - 事业：…
   - 财运：…
   - 感情：…
   - 健康：…
8. 注意事项：
```

### 4.2 注意事项

```
⚠️ 命理分析仅供参考，不能替代现实决策
⚠️ 八字相同的人命运不完全相同（受环境/教育/选择影响）
⚠️ 不要百分之百断言"吉"或"凶"，更多是"趋势"和"可能性"
⚠️ 不要用命理制造焦虑，要多给积极的建议
⚠️ 涉及重大决策（手术/投资/婚姻），建议结合现实情况
```

### 4.3 可回答的问题范围

```
✅ 今年运势怎么样？
✅ 我适合做什么工作？
✅ 财运好不好？
✅ 感情运势如何？
✅ 什么时候能结婚？
✅ 今年要注意什么？
✅ 我适合跟TA在一起吗？
✅ 搬家/换工作好不好？
✅ 今年适合投资吗？
✅ 我的健康要注意什么？

❌ 不算具体时间（哪一天会出事）
❌ 不算生死（大限、寿命）
❌ 不算他人隐私（别人八字没授权）
❌ 不做绝对断言（你一定会离婚）
```
