## 调候表使用说明

### 三步用法

```
① 出生月份→定位月份
② 日干→定位行
③ 查看第一用神+第二用神

例：农历三月（辰月）出生的甲木日主
→ 查「甲木+辰月」= 癸水(第1用神)、庚金(第2用神)
→ 结论：这个八字应该优先出现在四柱中的壬癸水或庚辛金
```

### 用神顺序说明

- **第一用神**：最重要。四柱中有一出现即算及格，两三个更好
- **第二用神**：辅助第一用神。有则锦上添花，没有也无大碍

### 用神出现位置的判断

| 位置 | 意义 |
|------|------|
| 用神在天干（透出） | 明显、公开的优势 |
| 用神在地支（暗藏） | 潜藏的优势，需大运流年引出 |
| 用神在年柱 | 先天禀赋，祖上余荫 |
| 用神在月柱 | 青年得势，事业有成 |
| 用神在日柱 | 自身能力强，中年发展 |
| 用神在时柱 | 晚年发力，子孙得力 |
