# 第一部分：面相基础

## 一、看面相的顺序

看面相一般按以下顺序来：

1. **看脸型** — 先定大框架（什么形状的脸）
2. **看十二宫** — 再分析脸上各个部位
3. **看气色** — 最后看脸色好坏、有没有光泽

记住：面相不是单看一个部位定生死，要综合看。

---

## 二、五种基本脸型

### 1. 蛋形脸（椭圆形脸）
- **特点**：上宽下窄，线条圆润，像鸡蛋
- **性格**：做事有条理，有计划性，文艺天赋高，适合搞艺术、设计类工作
- **运势**：一般比较顺遂，人缘好

### 2. 逆蛋形脸（倒三角脸）
- **特点**：额头宽，下巴尖，像个倒过来的鸡蛋
- **性格**：体力充沛，精力旺盛，竞争意识强，不服输
- **运势**：适合做开拓型工作，但容易冲动惹事

### 3. 长方形脸
- **特点**：额头到下巴基本等宽，脸的长度明显大于宽度
- **性格**：智慧高，洞察力强，爱思考，做事严谨
- **运势**：适合做学问、研究、技术类工作

### 4. 正方形脸（四角脸）
- **特点**：额头宽，下颌也宽，脸型方正
- **性格**：意志坚强，认准的事不回头，但容易冲动、固执
- **运势**：适合做管理、军警、体育类工作

### 5. 圆形脸（锅形脸）
- **特点**：整体圆润，肉多骨少
- **性格**：性格温和，乐观开朗，善于交际，人缘好
- **运势**：一般福气不错，生活安稳

## 三、面相十二宫（核心框架）

十二宫是把人脸分成十二个区域，每个区域管一类事情。这是面相学的核心框架。

### 1. 命宫（印堂）— 两眉之间
- **位置**：两眉之间那一块
- **管什么**：寿命长短、运气好坏、愿望能否实现
- **怎么看**：
  - 印堂宽亮、饱满 → 命好，运气顺
  - 印堂窄小、有疤 → 运差，多坎坷
  - 印堂发青发暗 → 最近运气不好，别冲动

### 2. 财帛宫（鼻子）— 鼻头
- **位置**：整个鼻子，重点是鼻头
- **管什么**：财运好坏
- **怎么看**：
  - 鼻头圆润有肉 → 财运好，能攒钱
  - 鼻头尖、无肉 → 财运一般，守不住钱
  - 鼻梁挺直 → 中年运势好

### 3. 兄弟宫（眉毛）
- **位置**：两边眉毛
- **管什么**：兄弟姐妹的关系、朋友缘
- **怎么看**：
  - 眉毛浓密 → 兄弟姐妹多、感情好
  - 眉毛淡疏 → 兄弟姐妹少或关系淡
  - 眉毛乱、断 → 跟兄弟合不来

### 4. 田宅宫（上眼睑）
- **位置**：上眼皮那一块
- **管什么**：家运、房产、祖业
- **怎么看**：
  - 上眼睑饱满 → 家运好，有房产
  - 上眼睑凹陷 → 家运差，易破财

### 5. 男女宫（下眼睑）— 也叫泪堂、卧蚕
- **位置**：下眼皮那一块（卧蚕）
- **管什么**：子女运、后代好不好
- **怎么看**：
  - 卧蚕饱满有光泽 → 子女有出息
  - 卧蚕发暗、有纹 → 子女运差

### 6. 奴仆宫（面颊下端）
- **位置**：下巴两侧靠下的位置
- **管什么**：下属、跟班、员工运
- **怎么看**：
  - 饱满圆润 → 得下属拥护，领导力好
  - 尖削无肉 → 管不住人

### 7. 妻妾宫（鱼尾）— 眼尾
- **位置**：眼睛尾部，鱼尾纹的位置
- **管什么**：夫妻关系、婚姻感情
- **怎么看**：
  - 眼尾光滑饱满 → 夫妻感情好
  - 眼尾纹乱、有痣 → 感情多波折

### 8. 疾厄宫（鼻梁中间）
- **位置**：鼻子的中间段（山根到鼻梁）
- **管什么**：身体健康
- **怎么看**：
  - 鼻梁挺直光洁 → 身体好
  - 鼻梁有节、发暗 → 容易生病

### 9. 迁移宫（额头两侧）
- **位置**：额头两边，靠近发际线
- **管什么**：外出、旅行、搬家、出国
- **怎么看**：
  - 饱满宽大 → 外出发展好，适合去外地
  - 凹陷窄小 → 守在家好，别乱跑

### 10. 官禄宫（额头中央）
- **位置**：额头正中间
- **管什么**：事业、职位、社会地位
- **怎么看**：
  - 额头饱满光洁 → 事业有成，能当官
  - 额头低窄 → 事业坎坷，难升职

### 11. 福德宫（眉尾上方）
- **位置**：眉毛尾部上方一点
- **管什么**：福气、好运、晚年运气
- **怎么看**：
  - 饱满有肉 → 有福气，晚年好
  - 低陷无肉 → 劳碌命，享福少

### 12. 相貌宫（整张脸）
- **位置**：整个脸面
- **管什么**：总体运势，综合性评价
- **怎么看**：综合看五官搭配、气色、比例好不好

## 四、其他重要面相知识

### 三停（上中下）
- **上停**（额头部分）：管早年运（0-30岁）
- **中停**（眉毛到鼻子部分）：管中年运（31-50岁）
- **下停**（鼻子到下巴部分）：管晚年运（51岁以后）

三停均匀 → 一生运势平稳
上停好中停差 → 早年好中年差
上停差下停好 → 先苦后甜

### 五官
- **耳**：采听官 — 肾气好坏、童年运
- **眉**：保寿官 — 寿命、兄弟朋友
- **眼**：监察官 — 心性、智慧
- **鼻**：审辨官 — 财运、健康
- **口**：出纳官 — 福气、饮食、表达

### 看气色
- **红润光泽** → 运气好，最近顺利
- **发青发暗** → 运气不好，注意意外
- **发黄发亮** → 财运不错
- **发白惨淡** → 身体或运势低迷

# 第二部分：手相基础

## 一、看手相的顺序

看手相要按步骤来，不能上来就看掌纹。正确顺序：

1. **看手的大小** — 跟身高体型比
2. **看手的长短** — 手指、手掌比例
3. **看手的软硬** — 手感质地
4. **看手指形状** — 每根手指的形态
5. **看掌纹** — 主要纹路
6. **看掌丘** — 手掌上的肉垫

---

## 二、手的大小、长短、软硬

### 手的大小
- **手大脚小**（手比身高比例大）：做事谨慎，想得多
- **手小脚大**（手比身高比例小）：胆大敢干，不拘小节

### 手的长短
- **手掌长**：比较感性，注重精神生活
- **手指长**：心思细腻，爱琢磨，文艺型
- **手指短**：行动派，说干就干，但缺乏耐心

### 手的软硬
- **手软**：性格随和，好说话，但可能怕吃苦
- **手硬**：意志坚定，能吃苦，但可能倔强
- **手软且厚**：有福气，生活安逸
- **手硬且薄**：劳碌命，辛苦奔波

---

## 三、手指形状

### 拇指
- **拇指长且直**：意志力强，有领导力
- **拇指短**：优柔寡断，没主见
- **拇指关节硬**：固执
- **拇指关节软**：随和，好说话

### 食指
- **比无名指长**：有领导欲，爱管人
- **比无名指短**：随和，不争不抢

### 中指
- **特别长**：责任心强，但容易操心过度
- **特别短**：性格懒散，不负责任

### 无名指
- **比食指长很多**：有艺术天赋，爱浪漫
- **跟食指差不多长**：平衡型，稳重务实

### 小指
- **长**：口才好，会说话
- **短**：不善表达，嘴笨
- **弯曲**：性格有点歪

## 四、五大掌纹

看手相主要看这五条纹，其他纹路是辅助。

### 1. 生命线
- **位置**：从食指和拇指之间（虎口），往下延伸到手腕方向，把拇指围起来
- **管什么**：寿命长短、体质好坏、生命力强弱
- **怎么看**：
  - 线长、深、连贯 → 身体好，长寿
  - 线短、浅 → 体质弱，但不是说短命
  - 线断断续续 → 身体容易出现波折
  - 线分叉 → 老来身体差
  - 线边上有一条平行线（姐妹线）→ 有贵人，福气大

### 2. 智慧线（头脑线）
- **位置**：从食指和拇指之间开始，横穿过手掌心
- **管什么**：聪明程度、思维方式、判断力
- **怎么看**：
  - 线长且清晰 → 脑子好使，逻辑强
  - 线长到底（到掌边）→ 聪明过头，容易想多
  - 线短 → 直来直去，想问题简单
  - 线往下弯 → 有想象力，适合搞创作
  - 线平直 → 务实，理性，适合搞技术

### 3. 感情线
- **位置**：从小指下面开始，横穿到食指方向
- **管什么**：感情好坏、人际关系、婚姻状况
- **怎么看**：
  - 线长、深、连贯 → 感情稳定，人缘好
  - 线断 → 感情有波折，容易分手
  - 线分叉 → 感情复杂，容易三角恋
  - 线尾往上翘 → 感情主动，不怕追
  - 线尾往下垂 → 感情被动，易受伤

### 4. 命运线（事业线）
- **位置**：从手腕附近开始，向中指方向延伸
- **管什么**：事业发展、人生际遇
- **怎么看**：
  - 线深、连贯 → 事业顺，有成就
  - 没有这条线 → 不代表没事业，只是靠自己打拼
  - 线断 → 事业有变动、跳槽
  - 线分叉 → 事业方向多，兼职多

### 5. 婚姻线
- **位置**：在小指根部下面，横着的小细纹
- **管什么**：婚姻好坏、感情状况
- **怎么看**：
  - 线清晰、一条 → 婚姻稳定
  - 线多（不止一条）→ 感情经历多
  - 线往上弯 → 晚婚
  - 线往下弯 → 婚姻不顺
  - 线断 → 离婚可能

## 五、掌丘（手掌上的肉垫）

掌丘就是手掌上鼓起来的肉包，每个丘管不同的事。

### 掌丘总表

| 掌丘名称 | 位置 | 管什么 |
|---------|------|--------|
| **金星丘** | 大拇指根部 | 爱情、感情、生命力 |
| **木星丘** | 食指根部 | 上进心、领导力、野心 |
| **土星丘** | 中指根部 | 责任心、命好不好 |
| **太阳丘** | 无名指根部 | 才华、艺术、出名 |
| **水星丘** | 小指根部 | 口才、商业头脑 |
| **第一火星丘** | 木星丘和金星丘之间 | 勇气、冲劲 |
| **第二火星丘** | 水星丘下面（掌边） | 忍耐力、自制力 |
| **火星平原** | 手掌正中间（被三大纹围起来） | 生命力、胆量 |

### 怎么看掌丘
- **丘鼓（饱满有肉）**：这方面的能力强
- **丘平（不鼓）**：这方面一般
- **丘塌（凹陷）**：这方面弱，需要补

## 六、其他手相知识

### 手型分类
- **方形掌**（实际型）：务实、守规矩，适合做稳定工作
- **尖形掌**（艺术型）：有才华、感性，适合搞艺术
- **圆形掌**（活动型）：好动、精力旺，适合跑业务
- **长形掌**（理想型）：爱幻想、气质好

### 常见特殊纹路
- **财运纹**（掌中出现口字纹或井字纹）：财运不错
- **克父纹/克母纹**（某些特殊位置的十字纹）：传统说法，不必太当真
- **性纹**（感情线和智慧线之间的小竖纹）：感情丰富

# 第三部分：身体语言（走相、坐相、睡姿）

## 走相（走路姿势）

- **走路快、步大**：性格急，精力旺，做事雷厉风行
- **走路慢、稳**：性格稳，不慌不忙，但可能拖沓
- **走路弯腰驼背**：没自信，心事重
- **走路抬头挺胸**：自信，有底气
- **走路脚跟拖地**：命苦，运势差（传统说法）
- **走路八字脚**：性格较倔

## 坐相（坐着的样子）

- **坐得安稳、不晃**：性格稳重，靠谱
- **坐不住、爱动**：性格急，注意力不集中
- **翘二郎腿抖腿**：心不定，焦虑，没安全感
- **坐姿懒散、瘫着**：性格随意，可能不靠谱
- **坐满整个椅子**：自信，有气场
- **只坐椅子边**：谨慎、紧张

## 睡姿（睡觉姿势）

- **仰面睡（大字型）**：性格开朗，不拘小节，自信
- **侧身睡（蜷缩型）**：性格内向，缺乏安全感，需要依赖
- **趴着睡**：性格急躁，好动，有掌控欲
- **面朝下趴睡**：压力大，心事重
- **喜欢缩成一团**：敏感，情绪化，需要人关心

# 综合判断原则

1. **不要看单一点就下结论** — 面相手相都要综合看，不能鼻子好就说财运好
2. **纹路和肉丘结合看** — 手纹好+掌丘好，才是真的好
3. **动态看，不是静态** — 面相手相会变，气色更是天天变
4. **看平衡** — 五官协调、三停均匀、手型掌纹搭配好，才是好相
5. **记得以德为先** — 面相手相只是参考，人的德行才是最根本的
