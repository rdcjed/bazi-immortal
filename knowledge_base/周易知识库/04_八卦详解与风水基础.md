# 一、先天八卦与后天八卦

## 先天八卦（伏羲八卦）

先天八卦是**伏羲**画的，讲的是**天地万物的本来样子**（宇宙的基本结构）。

### 方位图（南上北下）

```
        乾（南·天）
          |
   兑 -----|----- 巽
          |
        坤（北·地）
```

### 卦位对照表

| 卦名 | 卦符 | 方位 | 自然 | 数字 | 口诀 |
|------|------|------|------|------|------|
| 乾 | ☰ | 南 | 天 | 1 | 乾一 |
| 兑 | ☱ | 东南 | 泽 | 2 | 兑二 |
| 离 | ☲ | 东 | 火 | 3 | 离三 |
| 震 | ☳ | 东北 | 雷 | 4 | 震四 |
| 巽 | ☴ | 西南 | 风 | 5 | 巽五 |
| 坎 | ☵ | 西 | 水 | 6 | 坎六 |
| 艮 | ☶ | 西北 | 山 | 7 | 艮七 |
| 坤 | ☷ | 北 | 地 | 8 | 坤八 |

### 核心含义（《说卦传》原文翻译）

- **天地定位**：乾为天（南），坤为地（北）——天地定好了位置
- **山泽通气**：艮为山（西北），兑为泽（东南）——山和泽气息相通
- **雷风相薄**：震为雷（东北），巽为风（西南）——雷和风互相激荡
- **水火不相射**：离为火（东），坎为水（西）——水和火不相冲突

> 💡 **先天八卦重点**：讲的是"体"——宇宙本来的结构。数字是**乾1到坤8**，记住顺序就行。

后天八卦是**周文王**改的，讲的是**世界运行的规律**（春夏秋冬、东西南北怎么用）。

### 方位图（南上北下）

| 坤 | ☷ | 西南 | 土 | 夏秋之交 | 2 |

| 用途 | 说明 |

# 三、九宫飞星基础

## 洛书九宫

洛书九宫就是**后天八卦+中间**，一共9个格子，每个格子一个数字。

### 九宫格（戴九履一）

```
┌─────────────┐
│ 东南 │ 南 │ 西南 │
│  4   │ 9  │  2   │
├─────┼─────┼─────┤
│ 东   │ 中  │ 西   │
│  3   │ 5  │  7   │
├─────┼─────┼─────┤
│ 东北 │ 北  │ 西北 │
│  8   │ 1  │  6   │
└─────────────┘
```

### 九宫数字口诀

> **戴九履一，左三右七，二四为肩，六八为足，五居中央**

翻译：
- 戴九 = 头上是9（南）
- 履一 = 脚下是1（北）
- 左三 = 左边是3（东）
- 右七 = 右边是7（西）
- 二四为肩 = 两个肩膀是2（西南）和4（东南）
- 六八为足 = 两只脚是6（西北）和8（东北）
- 五居中央 = 中间是5

|------|------|------|------|------|------|

| 5 | 五黄廉贞星 | 💀大凶 | 土 | 中宫 | 大灾、大病、意外 |

## 三元九运

### 什么是三元九运？

把时间分成大周期：
- **1元 = 3运**（60年 × 3 = 180年）
- **1运 = 20年**
- **上元 + 中元 + 下元 = 三元 = 180年**

| 元 | 运 | 年份 | 星 | 五行 | 特点 |
|----|-----|------|-----|------|------|
| 上元 | 一运 | 1864-1883 | 一白 | 水 | 文化兴起 |
| 上元 | 二运 | 1884-1903 | 二黑 | 土 | 疾病较多 |
| 上元 | 三运 | 1904-1923 | 三碧 | 木 | 战乱争斗 |
| 中元 | 四运 | 1924-1943 | 四绿 | 木 | 教育发展 |
| 中元 | 五运 | 1944-1963 | 五黄 | 土 | 过渡混杂 |
| 中元 | 六运 | 1964-1983 | 六白 | 金 | 工业崛起 |
| 下元 | 七运 | 1984-2003 | 七赤 | 金 | 经济开放 |
| 下元 | 八运 | 2004-2023 | 八白 | 土 | 地产兴旺 |

> **我们现在在九运（2024-2043）**：九紫离火运，火的行业旺——互联网、人工智能、文化创意、美容、心理、电力能源。

## 八宅风水基础

八宅风水是最简单的风水门派——把房子按**坐向**分成八种类型。

### 什么是"坐"和"向"？

- **坐** = 房子背靠的方向
- **向** = 房子大门朝向的方向
- 比如：坐北朝南 = 背后是北，门朝南

### 八宅分成两大类

| 类别 | 房型 | 方位 |
|------|------|------|
| **东四宅** | 震宅（坐东朝西） | 东 |
| | 巽宅（坐东南朝西北） | 东南 |
| | 坎宅（坐北朝南） | 北 |
| | 离宅（坐南朝北） | 南 |
| **西四宅** | 乾宅（坐西北朝东南） | 西北 |
| | 坤宅（坐西南朝东北） | 西南 |
| | 艮宅（坐东北朝西南） | 东北 |
| | 兑宅（坐西朝东） | 西 |

### 每套房子有8个方位，吉凶不同

| 等级 | 名称 | 含义 | 适合做什么 |
|------|------|------|----------|
| 🟢 大吉 | 生气 | 财运、事业旺 | 大门、卧室、书房 |
| 🟢 次吉 | 天医 | 健康、治病 | 卧室、厨房 |
| 🟢 小吉 | 延年 | 婚姻、长寿 | 卧室、客厅 |
| 🟢 中吉 | 伏位 | 稳定、平安 | 神位、佛堂 |
| 🔴 小凶 | 绝命 | 官司、意外 | ❌ 忌开门、做厨房 |
| 🔴 次凶 | 五鬼 | 破财、火灾 | ❌ 忌开门、做卧室 |
| 🔴 中凶 | 祸害 | 口舌、争吵 | ❌ 忌做厨房 |
| 🔴 大凶 | 六煞 | 烂桃花、离婚 | ❌ 忌做卧室 |

> **简单用法**：知道自己房子的坐向，查出吉位在哪儿，把大门、卧室、厨房放在吉位；厕所、杂物放凶位。

# 四、风水基础

## 风水的核心——藏风聚气

**风水就四个字：藏风聚气。**

- **风**：风太大把气吹散了，不好；要"藏风"——风不能太急太直
- **气**：看不见的能量，要"聚气"——气要能聚在房子里不散
- **水**：水能"界气"——水能把气拦住，让气聚起来

> 🌬️ 简单说：好风水 = 风不大不小 + 气聚得住 + 有活水最好

### 好风水的标准

| 标准 | 白话解释 |
|------|---------|
| 背山面水 | 背后有靠山（安全感），前面有水（聚财） |
| 藏风聚气 | 风不要直吹，气不要散掉 |
| 阴阳平衡 | 不阴森也不暴晒，光线适中 |
| 山水环抱 | 四周有山环抱，像一把太师椅 |
| 明堂开阔 | 房子前面要开阔，不能堵着 |

## 形势派（峦头派）

形势派就是**看地形**的——看山怎么走、水怎么流。

### 龙穴砂水向——风水五要素

| 要素 | 白话解释 | 好标准 |
|------|---------|--------|
| 🐉 **龙** | 山的走势（山脉像龙一样） | 山势连绵起伏、有气势 |
| 🕳️ **穴** | 安坟建房的点位 | 穴位端正、不高不低 |
| 🏔️ **砂** | 穴周围的矮山 | 左青龙右白虎环抱 |
| 💧 **水** | 河流、池塘、道路 | 水要弯环、不要直冲 |
| 🧭 **向** | 坐向、朝向 | 坐吉向吉、符合八字 |

### 左青龙右白虎口诀

> **左青龙，右白虎，前朱雀，后玄武**

| 方位 | 神兽 | 要求 | 白话 |
|------|------|------|------|
| 左（东） | 青龙 | 要高一些 | 左边山要稍高 |
| 右（西） | 白虎 | 要低一些 | 右边山要稍低（白虎不能高过青龙） |
| 前（南） | 朱雀 | 要开阔 | 前面要空旷、有明堂 |
| 后（北） | 玄武 | 要有靠 | 后面要有山或高楼靠着 |

## 理气派（罗盘、方位）

理气派是**看时间和方位**的——用罗盘测角度、看什么时候吉利。

### 常用的理气方法

| 方法 | 说明 |
|------|------|
| **九宫飞星** | 每年九星飞到不同位置，吉位催旺、凶位化解 |
| **八宅风水** | 按房主命卦和房子坐向分东西四宅 |
| **玄空飞星** | 结合时间和空间的飞星，最精细的风水术 |
| **三合风水** | 根据水的流向和山的来脉看吉凶 |

### 罗盘的基本认识

罗盘 = 指南针 + 八卦 + 二十四山 + 各种圈层

**二十四山**：把360°分成24份，每份15°
- 12地支：子丑寅卯辰巳午未申酉戌亥
- 8天干：甲乙丙丁庚辛壬癸（戊己在中间）
- 4卦：乾坤艮巽

| 方位 | 包含的山向 |
|------|-----------|
| 北 | 壬、子、癸 |
| 东北 | 丑、艮、寅 |
| 东 | 甲、卯、乙 |
| 东南 | 辰、巽、巳 |
| 南 | 丙、午、丁 |
| 西南 | 未、坤、申 |
| 西 | 庚、酉、辛 |
| 西北 | 戌、乾、亥 |

> 💡 **给智能体的提醒**：普通用户不需要学会用罗盘，知道"每个方位有3个山向"就够了。

## 住宅风水基本禁忌

### 大门禁忌（大门是房子的"嘴"）

| 禁忌 | 为什么 | 怎么化解 |
|------|--------|---------|
| 🚫 大门对电梯 | 电梯开合像"剪刀"，气被切 | 门口放屏风或绿植 |
| 🚫 大门对楼梯 | 气顺着楼梯跑了（向下） | 门槛加高、挂门帘 |
| 🚫 大门对厕所 | 厕所秽气冲大门 | 常关厕所门、放绿植 |
| 🚫 大门对厨房 | 炉灶被门冲，不聚财 | 厨房门常关 |
| 🚫 大门对镜子 | 镜子把进门的气反射出去 | 移走镜子 |

### 卧室禁忌

| 禁忌 | 为什么 | 怎么化解 |
|------|--------|---------|
| 🚫 床对门 | 隐私差、睡眠不安 | 移床或挂门帘 |
| 🚫 床对镜子 | 半夜吓到自己 | 镜子用布盖着 |
| 🚫 床上方有梁 | 梁压顶、压力大 | 做吊顶包起来 |
| 🚫 床头靠窗 | 没靠山、不稳 | 床头移开窗 |
| 🚫 卧室有镜子 | 反射扰神 | 镜子放衣柜里 |

### 厨房禁忌

| 禁忌 | 为什么 |
|------|--------|
| 🚫 灶台对门 | 火气冲人 |
| 🚫 灶台对水槽 | 水火相冲（火水未济卦） |
| 🚫 灶台在西北 | 西北是乾位（父），火烧天门 |
| 🚫 厨房在正北 | 北方属水，水火不容 |
| 🚫 炉灶背后空 | 灶要有靠墙 |

### 厕所禁忌

| 禁忌 | 道理 |
|------|------|
| 🚫 厕所在房子中间 | 中宫是心脏，脏气居中 |
| 🚫 厕所门对餐厅 | 对着吃饭的地方不卫生 |
| 🚫 厕所对床 | 污浊之气影响健康 |
| 🚫 厕所没窗 | 湿气散不掉 |

### 客厅禁忌

| 禁忌 | 说明 |
|------|------|
| 🚫 横梁压沙发 | 坐的地方上有梁，压迫感 |
| 🚫 沙发背对门 | 没安全感、看不到谁进来 |
| 🚫 客厅太暗 | 阳气不足、家人沉闷 |
| 🚫 电视太大正对沙发 | 形成"火煞" |
| ✅ 客厅要明亮 | 明厅暗房是基本原则 |

## 办公室风水

### 办公桌位置

| 建议 | 原因 |
|------|------|
| ✅ 背靠墙 | 有靠山，安全感 |
| ✅ 面朝门 | 看得到谁进来（掌控感） |
| ✅ 右墙或右柜 | 加强白虎位（执行力） |
| ❌ 背对门 | 背后有人出入，不安稳 |
| ❌ 座位在门边 | 人来人往干扰大 |
| ❌ 头上是横梁或吊灯 | 压迫感、头疼 |

### 老板办公室

| 建议 | 说明 |

## 命主喜用神对应的方位/颜色

### 什么是喜用神？

八字里最需要补的那个五行就是**喜用神**。比如一个人火太多、水太少，那么**水**就是他的喜用神。

### 简单判断喜用神的方法（给智能体快速参考）

如果你是智能体且没有排盘功能，可以用这个简易判断：

1. **看季节**：出生在哪个季节，就大概率缺那个季节"克"的五行
   - 春（木旺）→ 土是喜用神（木克土）或金（克木）
   - 夏（火旺）→ 金是喜用神（火克金）或水（克火）
   - 秋（金旺）→ 火是喜用神（金克木之反，实际金旺喜火克金）或木（耗金）
   - 冬（水旺）→ 火是喜用神（水克火之反，实际水旺喜火暖局）或土（克水）

2. **看寒暖**（更简单）：
   - 生在寒冷的月份（亥、子、丑、寅月）→ 喜火（需要温暖）
   - 生在炎热的月份（巳、午、未、申月）→ 喜水（需要降温）

3. **看日主**（日干）：
   - 甲乙木日主 → 参考上面季节判断
   - 丙丁火日主 → 参考上面季节判断
   - 戊己土日主 → 参考上面季节判断
   - 庚辛金日主 → 参考上面季节判断
   - 壬癸水日主 → 参考上面季节判断
