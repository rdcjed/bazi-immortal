     7|## 一、这本书是啥？
     8|
     9|《周易六十四卦全解》是一本**讲《周易》64个卦的实用指南**。它不是那种高深莫测、玄之又玄的学术著作，而是**教你怎么在实际生活中用卦**——比如：
    10|
    11|- 事业不顺该咋办？
    12|- 生意能不能做？
    13|- 对象靠不靠谱？
    14|- 要不要出门？
    15|- 人生大方向怎么走？
    16|
    17|每讲一个卦，都从五个角度给出**大白话建议**：事业、经商、求名、外出、婚恋，最后还有一个综合「决策」总结。
    18|
    19|简单说：**这是一本古代版的「人生决策手册」+「职场指南」+「商业宝典」**。

    23|## 二、核心思想（一句话）
    24|
    25|> **万物都在变，关键是要看懂「势」，顺势而为。**
    26|
    27|书里反复强调几个道理：
    28|
    29|1. **阴阳平衡**——太强会衰，太弱会亡，中正平和才是王道。
    30|2. **物极必反**——好到极点就开始变坏，坏到谷底就开始好转（否极泰来）。
    31|3. **时机比努力重要**——该进则进，该退则退，该等就等。
    32|4. **做人要正**——不管干啥，道德得在线上，不然再好的卦也白搭。

   168|### 1. 遇到困难先看卦，别瞎撞
   169|> 书里反复说：**时运不佳就退，时机到了就上，别跟大势对着干。**
   170|
   171|比如：
   172|- 抽到 **乾为天** → 现在是你高光时刻，大胆干，但别飘
   173|- 抽到 **坎为水** → 现在麻烦事一堆，稳住，诚信做人，能熬过去
   174|- 抽到 **天山遁** → 形势对你不利，赶紧撤，保存实力
   175|
   176|### 2. 做生意的重点看「经商」
   177|书里对经商的分析特别接地气，很多建议放今天照样好用：
   178|- **诚信是根本**——几乎每个卦都在强调商业道德
   179|- **别贪心**——"适可而止"出现了无数次
   180|- **观察市场**——"随时注意市场动向"是高频词
   181|- **找靠谱的合作伙伴**——别跟小人一起干
   182|
   183|### 3. 感情婚姻看这些卦
   184|- **泽山咸** → 最吉利的感情卦，两情相悦
   185|- **雷泽归妹** → 婚姻卦但不太好，别强求
   186|- **天风姤** → 小心第三者，对象可能不正经
   187|- **火泽睽** → 夫妻容易闹矛盾，要包容
   188|
   189|### 4. 求职升职看这些卦
   190|- **地风升** → 步步高升，好运
   191|- **火地晋** → 晋升在望
   192|- **风山渐** → 慢慢来，别着急
   193|- **山地剥** → 现在不是时候，先忍
   194|
   195|### 5. 出门远行看这里
   196|- 大部分卦认为：**准备充分再出门**
